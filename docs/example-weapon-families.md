# 作例艦の武装系列

MC80 Home One／Liberty は添付図から採った上面50基・下面50基の球状砲配置を維持する。詳細は [図面に基づく配置](moncal-reference-armament.md) を参照。

MC系列とCIS艦は共通のモン・カラマリ球状砲を使用する。CR90とドレッドノート級の通常砲を明示し、廃止済みケースメイトの別名を経由して球状砲へ変わることを防ぐ。武装位置は既存の船体・構造物上に取り、砲座用の船体形状は追加していない。

MC30cは指定の500GT単装球状ターボレーザー16基（片舷8基）とPD10基を備える。既存の500GT単装球モデルと通常の発射周期を使い、大型イオン砲は搭載しない。

レキューザントの34TT砲には、旧舷側砲の12基／24基を含む。サブジュゲイターの34TT砲700基は背部・腹部の200基と旧砲列区画の500基。既存の艦尾・船首・舷側・上下面の担当区画と砲座数を維持した。ルクレハルクは赤道の42基を、各組2基のCIS速射砲と4基の球状砲に分ける。貨物型LH-3210は全砲を取り外し、荷役用トラクター6基を残す。

GR-75は自衛用の2連装レーザー砲塔2基のみを搭載する。CR90は200GT単装×2、200GT連装×2、2連装PD×4。帝国ドレッドノート級は200GT四連装×20、舷側ブリスターの200GT連装×10、2連装PD×10。ISD／ヴェネター／ネビュロンB／アクラメーターの指定編成は、それぞれの作例ビルダーで扱う。

`tests/example-weapon-families.cjs` は全艦の基数・系列、球状砲の船体接触点、左右のCIS速射砲、貨物型の非武装化を検証する。共通の推進・排熱改修に入る前の作例レシピを使用し、装備配置そのものを確認する。
