# 地上戦とウォーカー・戦闘車両の設計（PLAN-007 / PLAN-008）

艦が運ぶ連隊（中隊・車両）と、プレイヤーが設計したウォーカー・戦闘車両で戦う地上戦です。規則は `js/core.js` の `Ground`（Rts の後ろ）、画面は `js/app.js` の「v26 PLAN-007 / PLAN-008 ground combat」ブロックです。数値のうち映画・資料に由来しないものはすべて仮の値（provisional）で、`Ground.RULES`・`VD_K`・`DRIVES`・`INFANTRY`・`FORT` に集めています。

## ウォーカー・戦闘車両の設計（PLAN-008）

設計は共通の設計記録（仕様 §2.1）に `platform: 'walker' | 'vehicle'` を持つ形式 `ks-vehicle` 版1です。移動・戦闘の規則は艦艇と別ですが、兵装は艦船・艦載機と同じ `Core.FITS` を `Core.fitSpec` の倍率で使い、費用は艦艇と同じ `Core.quoteCostBOM` で見積もります。

| 項目 | 内容 |
| --- | --- |
| 車体 | 全長・全幅・高さ、形（箱形・楔形・円筒） |
| 走行 | ウォーカー：二脚・四脚・六脚と脚の高さ／車両：無限軌道・装輪・リパルサー |
| 装甲 | 前面・側面・後面（cm）、偏向シールドの有無 |
| 武装 | 兵装・倍率・門数・取付位置（最大8行） |
| 乗員・動力 | 乗員・兵員、リアクター（自動＝必要量の110%、または出力指定）、陣営 |

`Ground.vehicleStats` が質量・最高速度・耐久・装甲・対装甲／対歩兵／対空火力・射程・視認距離・必要出力・建造費・格納サイズと警告を出します。速度は駆動方式の基準速度（AT-ST 90 km/h・AT-AT 60 km/h は原作どおり）に、動力の充足・質量・脚の長さを掛けたものです。兵装の貫徹力・損害・射程はボルトのエネルギーの立方根に比例し（戦闘機のレーザー砲で 17 cm・約1 km）、発射管は弾倉の弾数を持ちます。

既存の車両種別（`Core.VEHICLE_TYPES`）は作例です。公式の寸法・乗員・兵員をそのまま使い、形は汎用の箱・楔・脚の組み合わせ、武装と装甲は役割からの推定です（`EXAMPLE_SPECS`）。

保存はこの端末の `yard.vehicles`（アカウントの保存先があればそこに `kind: 'vehicle'`）で、艦の設計図一覧とは混ざりません。JSON の書き出し・読み込みもできます。保存した設計は `Ground.registerVehicleDesign` で設計内容から作る鍵（`vd…`）の車両種別として `Rts.VEHICLES` に登録され、艦隊編成の中隊の車両に加えられます。中隊はその時点の設計を `vdesigns` に持つので、元の設計を変えたり消したりしても編成済みの車両は変わらず、別の端末・再読み込みでも復元されます。

タイトル：サンドボックス → 設計 → **ウォーカー・車両設計**。

## 地上戦（PLAN-007）

3 km × 2 km、100 m 四方のマスの地図（平地・森林または市街・丘陵・水域）で、惑星の種類で地形の割合が変わります。目標は3か所（A・B・C）。乱数はすべて戦闘のシードから引くので、同じ設定とシードなら同じ結果になります（自動で決着も同じシミュレーション）。

- **部隊**：歩兵中隊（144名、分離主義勢力はバトル・ドロイド）と車両小隊（同じ種別4両まで）。地上戦に出るのは艦の連隊（`sh.ground`）の中隊と、その車両・自作設計の車両です。防衛側は人口に応じた守備隊（2＋人口×2個中隊、陣営の連隊構成の車両、人口3以上なら各目標に陣地）。
- **揚陸**：攻撃側は艦の揚陸艇（`Core.stowLoad` の lift：一度の出撃で降ろせる兵員と車両の格納サイズ、貨物室の寸法）で240秒ごとに降下地点へ降ります。貨物室に入らない車両や揚陸艇のない部隊は降ろせません。
- **命令**：降下地点の決定（展開）、移動、攻撃（敵部隊をタップ）、待機（陣地構築：時間とともに遮蔽が増す）、目標奪取、航空支援。経路は地形を考えて自動で選びます。
- **射線と遮蔽**：丘陵は射線を遮り、森林・市街は100 mを超えて見通せません。背の高いウォーカーや丘の上の部隊は遠くまで見えます。撃った部隊は撃たれた側に見つかります。森林・丘陵・陣地構築は歩兵の損害を減らします。
- **戦闘**：装甲は前・側・後面で別。貫徹すれば全損害、しなければ大きく減ります。歩兵は小銃射撃と対装甲班（小隊ごとに1基）。射撃を受けると制圧され、命中と移動が落ちます。
- **航空支援**：艦隊の爆撃機・ガンシップ4機ごとに1回（最大12回）。要請から約20秒で着弾、45秒の間隔。敵の対空火器が近いと撃墜されて威力が半分になります。味方も巻き込みます。
- **勝敗**：攻撃側は全目標を60秒保持するか、守備隊の戦力を10%以下にすれば勝ち。攻撃側の戦力が15%以下になるか、制限時間（1時間、演習50分）が来れば防衛側の勝ち。撤退もできます（防衛側の勝ち）。損害は中隊ごとに艦の連隊へ書き戻します（`Ground.applyLosses`）。

画面は地図を全面に、命令ボタンと部隊一覧を下に並べたスマートフォン優先の配置です。部隊をタップで選び（「複数選択」「全部隊」もあり）、地図をタップで移動、敵をタップで攻撃、目標の円をタップで奪取。速度は一時停止・1×・4×・16×、拡大は3段階（拡大時はドラッグで移動）。

### 演習（PLAN-025 段階7）

タイトル：サンドボックス → **地上戦演習**。陣営の1個大隊（4個中隊と所属車両）を LAAT/i 12機・LAAT/c 2機で降ろし、仮想敵（3個中隊・戦車2両・陣地1か所）が守る目標を奪います。画面右上の手順（展開・移動・攻撃・ウォーカー／車両への命令・航空支援・目標奪取）が、実際に操作すると消えていきます。自作のウォーカー・車両を両数を決めて加えられ、設計画面の「地上戦で試す」からも始められます。キャンペーンの段階 `ground` はこの演習を使う想定です（キャンペーン本体は未実装）。

### 任務での揚陸

任務の銀河図で、敵艦隊のいない星系（制宙権）に自軍の任務群がいて、その艦が連隊を積んでいれば、星系の欄に「揚陸作戦」が出ます。自陣営の惑星と地表のない惑星（ガス惑星）は対象外です。艦隊戦に勝って敵艦隊が消えたときは、結果の欄でその星系を案内します。守備隊はその星系を支配する陣営（どこにも属さない星系はその星の防衛軍）です。勝てば惑星を確保し（保存データの `held`）、損害は各艦の連隊へ、経過時間は任務の時計へ反映します。

### 艦隊戦での揚陸

艦隊戦で、有人惑星のある星系に戦闘可能な敵艦がいなければ、陸戦部隊を積んだ任務群の欄に「揚陸作戦」が出ます。揚陸は艦隊戦の時計で自動で戦われ（`Ground.landingTick`。艦隊戦が先に決着した場合はその時点で最後まで戦われます）、「地上戦を見る」で観戦できます。勝てばその星系は確保され（`sector.systems[i].held`）、出来事に記録されます。航空支援は任務群の艦に収容中の爆撃機・ガンシップが飛びます。降下には、艦隊戦では発艦せず艦内にとどまる揚陸艇（LAAT/c・センチネル級・歩行機降下バージ・C-9979 など）も使います（編成の `landers`）。

## 保存形式

- 新規：`yard.vehicles`（設計の配列）、任務の `held`（星系→陣営）と `stats.landings / taken`、中隊の `vdesigns`（鍵→設計）。いずれも無ければ空として読み、古い保存データはそのまま読めます。
- 艦隊戦の `w.landings` は戦闘中だけのもので保存しません。
