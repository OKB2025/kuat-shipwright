# 船体パーツの拡大縮小と切り取り（v24）

船体パーツ（船体構造物）の大きさを変えると、そのパーツが持つ切り取りも同じ倍率で付いていく。以前は、船体の形だけが拡大縮小され、切り取りは元の位置と大きさのまま残っていた。

船体の形は、長さ・幅・高さに対する割合で決まっている。そのため拡大縮小の中心は、艦尾（x 0）、竜骨（y 0）、中心線（z 0）になる。切り取りはメートルで記録されているので、同じ中心から次のように倍率を掛ける（`scaleHullStructureCuts`）。

| 切り取り | 変わるもの |
| --- | --- |
| 立体の切り取り | 中心と大きさ。回転した切り取りは、その軸ごとに伸びた分だけ大きくする |
| トレンチ | 高さ（高さの倍率）と深さ（幅の倍率）。範囲はもともと長さに対する割合 |
| 箱形の切り欠き | 範囲の箱 |
| 縁の面取り | 内側への幅（幅の倍率）と落とし高さ（高さの倍率）。割合で指定した面取りも同じ（その値は断面の幅・高さの割合を掛けるメートル値なので、倍率を掛けないと形が変わる）。2026-11-11 修正：以前は割合指定の面取りと落とし高さに倍率を掛けておらず、船体寸法を変えると面取りの形が変わっていた |
| 平面形の切り込み | もともと割合なので変わらない |
| 開口部（ハッチ） | 位置・幅・開口の範囲 |

大きさの欄を直接変えたときも、「船体の寸法」から変えたときも、同じように働く。

## 統計の途中結果（2026-11-11 修正）

構造物の材料計算（`structuralMaterial`）は、同じ艦のオブジェクトで計算し直すとき途中の和集合（`STRUCTURAL_PREFIX`）を使い回す。船体の形が変わっても最初の段（変更前の船体の境界と容積）を使っていたため、エディタの Worker では船体寸法を変えたあとの容積・質量が、読み込み直した場合と食い違っていた（インペリアル級の全長を 2,200 m にすると 140.4 Mm³ ⇔ 143.1 Mm³）。船体の形が同じときだけ途中結果を使う。
