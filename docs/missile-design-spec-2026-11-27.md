# ミサイル・魚雷の設計化（仕様メモ 2026-11-27）

ミサイルと魚雷を、案A（被弾判定と耐久を航空機と同じにする）と案B（航空機と同じ「飛んでいる物体」にする）を混ぜた形で作り直すための仕様メモです。
このファイルには、ユーザーが決めたことと、まだ決まっていないことを分けて書きます。実装は、今の作業ブランチ（`claude/inspiring-faraday-kn13yq`）をマージした後に、別のブランチで行います。

## ユーザーの決定

| 項目 | 決定（ユーザーの言葉） |
| --- | --- |
| 方式 | 「案AとBを混合する」 |
| 構成 | 「ミサイル魚雷は『弾頭部』『推進剤』『弾芯』に分ける」 |
| 弾芯 | 「弾芯は無しから鉄〜タングステンくらいまで密度を変えることができ、それに従い重量が増える。密度は貫通力に繋がる」 |

| 大きさ（艦艇） | 「艦艇搭載ミサイル/魚雷は発射機サイズに収まる大きさ」 |

## 今のコードとの関係（2026-11-27 時点）

- 弾の定義：`ordnanceBody(直径, 長さ, 弾頭の割合)`（`AIR_ROUNDS`、`SHIP_TORPEDO`、`SHIP_MISSILE`）。速度は種類ごとの固定値で、`ROUND_SPEED` と `MISSILE_FLIGHT` にあります。
- 発射時の速さ：`MISSILE_FLIGHT.launch` は 220 m/s です。母艦の速度は足していません。決定どおり、母艦の速度＋発射機の向きに 200 m/s へ変えます。
- 貫通：v30 の貫通モデル（`docs/damage-penetration.md`、js/core.js の 111912 行付近）。弾芯の運動エネルギーと密度・直径を渡します。
- 誘導：`seekMode`、`shipGuide`、`heatP`、`semiActive`、`inertial` がすでにあります。今は弾の種類で決まっていますが、設計で選べるようにします。
- 迎撃と被弾：1 発の弾は、1 発目の被弾で誘導を失って直進し、2 発目で消滅します（`pointDefenseRoundHits`）。これを耐久値の仕組みに置き換えます。
