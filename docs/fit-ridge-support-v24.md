# 稜線・頂点への上面配置（v24）

楔形の頂点や、二つの斜面が交わる稜線の上には、装備を上面配置できなかった。その位置には、指定した向き（真上）に向いた面がないためである。

v24 では、取付位置が追加元の形状の表面上にあり、指定した向きと面の向きの差が約78°以内なら、配置できる。

- 装備は指定した向きのまま立つ。斜面に合わせて傾かない。
- 砲塔の下には支持台が自動で付き、足元の斜面まで埋める（`mountTurretSupport`）。支持台の上面は、足元で一番高い点（稜線・頂点）になる。そのため砲塔は追加元にめり込まない。
- 砲塔以外の装備は、足元の高さに合わせた台の高さ（`base`）で同じように立つ。
- 追加元の表面から離れた位置は、今までどおり配置できない。
