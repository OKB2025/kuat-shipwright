# 表面の2点で引く砲列（設計案、2026-11-10）

ユーザーの提案：「トレンチに設置」から、「表面上の始点と終点の2点を選び、どこでも配置できる」砲列へ、砲列の仕組みを変える。この文書は設計案で、まだ実装していない。

## いまの仕組み（トレンチ砲群）

- 艦の `trenches`（トレンチの切り取り）に、砲種と舷ごとに1つずつ「砲群」の装備を作る（`configureTrenchArmament` → `syncTrenchArmament`、`js/core.js`）。
- 砲群は数（`aggregateCount`）を持つ1つの装備として扱う。射撃・描画の代表点は最大8点（`trenchMuzzles`）。射界は壁の法線から±85°×±20°（`TRENCH_BATTERY_ARC`）。蓄電は共有の充電区画（`trenchGroupCompartment`）、損傷は砲群ごとのモジュール、艦隊戦は `trenchProfileMount`、試験航行は `gfx.js` の記述子で扱う。
- 並べられる数は、トレンチの開口の長さと高さで決まる（`trenchArmamentPacking`）。

困っている点：
- トレンチの中にしか置けない。
- 船体の形を変えると、収まる数が変わる。エグゼクターでは、トレンチの開始を艦首側へ移したら 1,880 基から 1,390 基に減った。
- トレンチのために、舷側帯を垂直・高さ140 m 以上に保つ必要があり、船体を原本に合わせにくい。
- 砲種はトレンチ用の一部だけ（`quad70Side`・`pd`・`ion`・`monCal34` など）。旋回砲塔の `oct40`（40 TT 8連装）は使えない。

## 案：砲列（バッテリー・ライン）

### データ（保存形式に追加）

```
ship.batteryLines = [{
  id, host: 構造物 id | 'hull',
  a: [x,y,z], b: [x,y,z],            // 表面上の始点・終点（ワールド座標。保存時は host の局所座標も持つ）
  aLocal, bLocal, normalA, normalB,   // 面の向き（取付面の法線）
  rows: 1..n,                         // 列数（線に直交する方向の段数）
  kind: 'oct40' | 'quad70Side' | ..., count,
  arc: {yawDeg, pitchDeg},            // 既定は砲種ごと
}]
```

### 経路

- 砲列は基本的に**面ごと**に設定する（ユーザー決定、2026-11-10）。
- 2点の間を、host の表面に沿って結ぶ。2点を結ぶ直線を表面へ投影した折れ線にする。
- 経路が面を横切る場合（稜線・面の境界をまたぐ）は、**自動的に面ごとの砲列に分離する**（ユーザー決定）。分離した各砲列は、元の指定（砲種・列数）を引き継ぎ、数は各区間の長さで配分する。

### 収容

- 砲種の砲座の幅（`fm`）と高さ（`hm`）で、線に沿った間隔と段数を決める。数が収まらなければ、理由と収まる上限を返す（今の「収容できません」を、上限の数つきにする）。
- 砲座の下は、既存の支持台（`mountTurretSupport`）と同じ扱いで面に固定する。

### 射撃・損傷・給電（トレンチ砲群の仕組みを流用）

- 1本の砲列を1つの集約装備（`aggregateCount`）として扱う。
- **照準線は砲列に沿って 50〜100 m ごとに1本**（ユーザー決定）。照準線ごとに目標・射界・射線の遮りを判定し、その区間の砲がまとめて撃つ。砲列の長さ L に対して本数 n = max(1, ceil(L/100))、間隔 L/n（100 m 以下、L≥50 m なら 50 m 以上）とする。今のトレンチ砲群の代表点（最大8点）はこれに置き換える。
- 射界は照準線の位置の取付面の法線を基準にする。旋回砲塔（`oct40` など）は砲種の旋回範囲を使い、舷側砲は±85°×±20°にする。
- 射線の遮り、蓄電、損傷、艦隊戦の射撃（`trenchProfileMount` 相当）、試験航行の記述子（壁の法線基準）は、トレンチ砲群の実装をそのまま一般化する。

### トレンチとの関係

- トレンチ砲群は「トレンチの壁の上に引いた砲列」として移し替える。古い保存データの `trench.armament` は、読み込み時に砲列へ変換する（数・砲種・舷を保つ）。
- トレンチが要らない艦は、舷側帯の制約を外せる。エグゼクターは船体を原本にさらに近づけられる。

## 作業の分け方（案）

1. **Core**：`batteryLines` のデータ、経路と収容の計算、集約装備の生成（トレンチ砲群の関数の一般化）。保存・読み込みと旧データの変換。テスト。
2. **戦闘**：艦隊戦・RTS・試験航行の射撃を砲列に対応させる（いまのトレンチ用の分岐を一般化）。射界・遮り・損傷のテスト。
3. **エディター**：砲列モードで、表面上の2点をタップし、砲種・数・列数を選ぶ。プレビュー、Undo/Redo、配置失敗の理由表示。
4. **作例**：エグゼクターの砲を40 TT 8連装の砲列に置き換え、舷側帯の制約を外して船体を当てはめ直す。
