## 1. ロック元のマークと対応判断

- 自艦をロックしている相手は、敵であると分かる。
- それまで存在を全く把握していなかった相手であっても、ロック元は必ずマークする。
- マークしたうえで、逃げるか反撃するかは、その艦・艦隊の判断による。

## 2. 艦隊単位の追跡と個艦へのロック

- 基本は、ひとまとまりの艦隊を追跡する。
- 発見した艦をすべて個別に追跡し続ける方式を基本としない。
- ロックする対象は個別に指定する。艦隊の追跡と、個艦へのロックを区別する。

## 3. チャンネルの運用

- 現在攻撃している艦や、動きが気になる艦以外には、原則としてチャンネルを割り当て続けず、空きを確保する。
- 対空、およびミサイル・魚雷への長距離迎撃も同じチャンネル枠を使用する。
- このため、発見した敵艦の個別追跡だけでチャンネルを埋めない。

## 4. 点防御の目標選択

- 各点防御は、その点防御に最も近いミサイル・魚雷・航空機を狙う。
- 距離の基準は、それぞれの点防御の位置とする。
