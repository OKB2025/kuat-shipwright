# 武装モデルの寸法基準

現行の40TT・70TT・175TT・720TT砲塔、球形砲塔と500GT・200GT砲塔の系列は、ユーザー提供のインペリアル級と砲塔比較写真を基準にした標準寸法を使う。これらの系列以外の通常砲は、従来の出力比による寸法換算を保持する。形状ごとの縦横比と取付原点を共通の描画・選択判定へ反映する。

## 写真を基準にする砲塔

`single40`、`quad40Ion`、`twin40Dome`、`twin40`、`triple40`、`oct40`、`refVen`、`triple70`、`quad70Side` の9種類はモデル倍率1、`calibration: isd-photo-family`。球形のイオン4連装、半球形のターボレーザー連装、箱型のターボレーザー連装を区別する。球形イオン砲は高さの約1/3を取付面へ埋め込み、球体と4門が一体で照準する。ISD主砲は従来の通常 `isd_heavy_octuple`（1,436頂点・1,104面）の形状を保ち、全長40 m・全高約10.569 m・全幅約40 mへ一様に寸法調整し、DBY-827も元の `ven_turret` の形状を保つ。各モデルを一斉射出力比で再縮小しない。

全9種類の寸法、形状と写真の読み取り条件は [砲塔系列と砲室区画](turret-family-and-compartments.md) と生成マニフェストを参照。新規配置時は支持台を自動生成しない。既存設計の明示的な手動砲座は保持する。

[写真の測定記録](../assets/source/turret-photo-measurements.json) に基づき、砲室長・高さ、円形基部の直径、砲身長を独立に調整する。40TT単装の長い砲身、半球型連装の広い砲室、箱型連装・3連装の上部機構の比率をそれぞれ保持する。40TT系列の砲身長は写真中の各形式に従い、70TT系列の9門は共通のDBY-827砲身長を使う。写真1の円盤直径を基準にした読み取りには約13%の許容差があり、斜視写真の投影比には透視の不確かさも含む。

箱型40TT連装と3連装は同じ22.5 m × 13 mの固定外殻を使う。3連装の幅広い可動装甲フードと揺架は横軸から受筒・砲身へつながり、0度で中央開口を埋める。可動機構のために確保する空間に従って、充電設備へ使える容積を決める。

すべての砲塔の表示色は現行40TT×8に統一する。塗装は描画用コピーの色とテクスチャ座標で揃える。形状は、今回の旧40TTイオン球の砲身更新を除いて既存参照アセットを保持する。40TT×8自身の塗装は保持する。

500GT・200GTの6種類は `single500`、`twin200`、`quad500`、`quad200`、`single200`、`twin200Fast`。いずれも倍率1、`calibration: light-photo-family` とし、40 mの既存8連装を含む同じ写真から相対寸法を決める。写真中の展示台を除き、球形単装、左右連装、上下にずれた連装速射砲、外付け砲基部の四連装を区別する。形状と寸法は [500GT・200GT砲塔系列](light-turret-family.md)、測定条件は [写真の測定記録](../assets/source/light-turret-photo-measurements.json) を参照。

`quad500` の本体は今回添付された `arquitens_turret.stl` を基にし、左右の円形基部と縦2門ずつの砲身を最新写真に合わせて作り直す。写真から読む全長の目安は約28.5 mで、以前の点防御由来モデルの17.8304 mは使わない。1門0.5 TT、4門合計2 TTを保持する。`quad200` は40TT外付け連装の縮小形状を基にした4門×0.2 TT、合計0.8 TTで、従来の汎用砲の寸法換算からこの個別写真基準へ移す。

## 系列以外の出力換算

今回の大型8連装への更新によって、系列以外の通常砲まで一律に大型化しないよう、従来の換算密度を保持する。

| 換算の基準 | 一斉射出力 | 密度計算に使う包絡寸法 X × Y × Z（m） |
| --- | ---: | --- |
| DBY-827連装 | 140 TT | 28.861992 × 9.997709 × 16.258085 |
| 従来のISD重砲筐体 | 320 TT | 29.679587 × 7.842050 × 29.679456 |

後者は引き続き保持する `isd_heavy_twin` の元形状寸法から求める。現行の40 m級 `oct40` の包絡を汎用砲の換算密度には使わない。ここでの体積はモデル包絡箱の体積であり、砲室の実容積や充電区画ではない。

門数を `n`、一斉射出力を `E`、元の包絡体積を `V0` とすると、以下で決まる。

```text
t = clamp((n - 2) / 6, 0, 1)
ρ2 = DBY-827の包絡体積 / 140 TT
ρ8 = 従来のISD重砲筐体の包絡体積 / 320 TT
Vtarget = E × ((1 - t) × ρ2 + t × ρ8)
倍率 = cbrt(Vtarget / V0)
```

一斉射出力はターボレーザーの `tt`、イオン砲の等価出力 `ion`。連射間隔で割った毎秒出力は使わない。3軸に同じ倍率を掛けるので縦横比を保つ。威力、連射間隔、質量、乗員数、費用は寸法倍率で再計算しない。航空機用武装、固定武装、ミサイル、トラクタービーム、超兵器、艦橋設備は対象外。

## 350TT連装重砲と既存設計

`stl` は2門×175 TT、合計350 TTの2連装重ターボレーザーで、70TT三連装に近い角形の砲塔を使う。`ion`・`utl`を含む新しい9種類は `calibration: capital-photo-family`、倍率1。175TTの2・3・4連装は60×16.425×45m、720TT連装は90×24.75×67.5m、ボール4種は44.5×36×36mを使う。通常175TT三連装は連装と同じ本体・砲基部へ中央の1門を追加する。角形・お椀型175TTの前部機構だけを0.8倍にし、本体と砲身、球形4種と720TT連装のモデルは保持する。詳細は [175TT・720TT砲塔系列](capital-turret-family.md) を参照。従来の `isd_heavy_twin` は元資料と汎用寸法換算の基準として残し、`stl`の描画には使わない。現行320TTの`oct40`は引き続き元の通常8連装を使う。

従来の6連装砲、ISD由来モデルのイオン砲、8連装ケースメイトは廃止し、旧設計を次の定義へ移行する。武装ID、配置、対称関係、充電設定を保持し、廃止モデルのスキン指定を除く。

| 旧定義 | 移行先 |
| --- | --- |
| `refISD`（6連装350 TT） | `stl`（2連装350 TT） |
| `refISDh`（8連装350 TT） | `oct40`（8連装320 TT） |
| `refIon` / `refIonH` | `ion`（175TT×2のイオン砲） |
| `casemate40`（8連装ケースメイト） | `broadsideBattery`（40TT×2の側面砲列区画） |
| `refSide`（ヴェネター側面砲80 TT） | `twin40`（2連装80 TT・1秒間隔） |
| `xx9`（XX-9・80 TT・4秒間隔） | `twin40`（2連装80 TT・1秒間隔） |
| `nk7`（NK-7・イオン40 TT・4秒間隔） | `quad40Ion`（4連装イオン160 TT・1秒間隔） |

表面武装、テンプレート、搭載艦にも同じ移行を適用する。旧 `ven_turret` / `dby_twin40_raised` のスキンを持つ対象系列は現行のモデルへ移行する。既存の140TT連装 `htl` はDBY-827のモデルへ統合し、IDを保つ。旧ヴェネター側面砲 `refSide` と旧XX-9 `xx9` は `twin40`、旧NK-7 `nk7` は `quad40Ion` へ移行し、旧カタログ項目は残さない。

## 小型両用砲

点防御の `pd` は軽ターボレーザーと統合し、1門20GTの連装軽砲とする。

外観は手続き生成の砲塔（1基154三角形）。以前のFBXモデルは資料として扱い、描画には使わない。基準外形（9 × 3.149 × 5.730 m）は維持し、新しい20GT出力から通常の倍率を計算する。

- 2門×20GT、一斉射0.04TT、連射間隔0.2秒、毎秒0.2TT。
- 対空値6、`dualPurpose: true`。
- 元モデル9 × 3.149338 × 5.729853 m、20GT出力での換算後は約1.819 × 0.636 × 1.158 m。

砲室内の実容積による充電設備の配置は寸法換算と分離する。包絡体積を充電容量として扱わず、モデルとともに定義された閉じた砲室領域を同じ倍率で変換する。

## 実装と検証

`Core.weaponModelScale(f)` はモデル倍率、`Core.weaponSizing(f)` は元寸法・元包絡体積・換算先体積・門数・一斉射出力・基準間の補間値を返す。手続き生成砲は標準寸法へ倍率を反映し、参照モデルは同じ倍率をモデル変換へ適用する。描画、選択、衝突包絡で同じ寸法を使う。

個別砲の手動サイズUIや新しい保存値は追加しない。旧保存の `f.scale` は既存の正規化で除き、読み込みを繰り返しても寸法補正を累積させない。

```sh
node --test tests/weapon-output-sizing.cjs tests/weapon-family-models.cjs \
  tests/turret-photo-proportions.cjs tests/weapon-plain-metal-uv.cjs \
  tests/weapon-flush-bounds-core.cjs tests/turret-rotation-core.cjs \
  tests/turret-rotation-transform.cjs tests/weapon-catalog-migration.cjs
```

40TT・70TT・500GT・200GT写真系列の倍率1、系列以外の換算密度の維持、出力と門数の換算、点防御の能力、対象外装備の寸法、6方向・傾斜・旋回時の包絡、保存の往復と旧系列の移行を対象にする。
