# 軍用作例の最大加速度

マンデイターIIはユーザー指定の約2,000Gへ調整する。加速度の資料値・指定値がない軍用作例も約2,000Gを設計目標とする。ユーザーが補助艦艇と指定したネビュロンBとゴザンティは、それぞれ約1,000G・約500Gを目安にする。民間輸送船には軍艦用の一律目標を追加しない。これらは作例の設計値であり、作品で公表された性能値としては扱わない。

| 作例 | 設計目標 | 根拠 |
| --- | ---: | --- |
| マンデイターII | 約2,000G | 今回のユーザー指定 |
| ドレッドノート、ルクレハルク戦艦 | 約2,000G | 未設定の軍用艦に対する設計目標 |
| ミュニフィセント、オナガー | 約2,000G | 同上 |
| プロヴィデンス／大型型、レキューザント／大型型 | 約2,000G | 同上 |
| サブジュゲイター、共和国小型輸送艦 | 約2,000G | 同上 |
| ネビュロンB | 約1,000G | 補助艦艇として低速でよいというユーザー指定に基づく目安 |
| ゴザンティ | 約500G | 同上。元のナセルに収まる実容積を優先 |
| エグゼキューター | 機関定格3,300G | 既存参照表の値。実際の最大加速度は構造上限も適用 |
| ヴェネター | 3,000G | 既存参照表の値 |
| アクラメイター | 3,500G | 既存参照表の値 |

以前のユーザー指定は維持する。インペリアルI／IIは2,300G、アーキテンスは1,800G、CR90とMC系列は2,100G、スフィルナは約2,500Gとする。GR75、ヘラクロン、貨物型LH3210には今回の軍艦向け目標を追加しない。

## 実機関による調整

機関本体の実容積から通常定格の入力と推力を求める。15作例は通常定格で機関の実容積を拡大する。通常定格の係数は従来どおり入力 `3.4e17 W/m³`、推力 `1.7e8 N/m³` とする。必要な推力は実際に搭載する機関を大きくして確保し、完成した艦の質量から加速度を計算する。機関・支持設備・配電・動力伝達路・排熱設備の追加質量も含める。

ヴェネターは8基のノズルを保持し、全機関の実体を拡大したうえで、有限な機関室に収まらない分を高負荷定格で補う。受電入力に応じる効率低下、追加発熱、冷却電力と設備を同じ式で計上する。定格上限は既存の高密度仕様の範囲内とし、艦種だけの推力倍率は加えない。

内蔵機関は実際の船内容積に収める。外装機関は実体のある外部機器として扱い、大きくした部分の形状と質量も計上する。船体・ノズルの開口位置・武装を保ち、他の機器との衝突を検査する。外装と本体を別々の寸法のまま残さず、実際の外装断面に本体を収める。不足する外装は径・長さを広げる。エグゼキューターは13基の独立した外装機関を保持し、必要な伝達容量に合わせてノズル径も拡大する。開口位置は維持する。内部機器を移す場合も、反応炉とシールドの実容積・性能は維持する。

構造強度と慣性補償による上限を含めて、設計時の最大加速度を確認する。反応炉の出力は、推進・砲撃・シールド・冷却で共有する。実際の同時運転では給電・損傷・厳格排熱による制限が残る。

構造と慣性補償を含む最大加速度が各目標の±5％に収まることを確認する。約2,000Gの作例は1,900～2,100G、ネビュロンBは950～1,050Gとする。ゴザンティは元の丸いナセルに収まる実容積を優先し、定格450～550G・実最大450～525Gを確認範囲とする。エグゼキューターは既存の3,300Gを機関定格の目標として保持し、構造限界による実際の最大加速度を別に記録する。参照値に表示を合わせるために構造限界の計算式を変更しない。

調整は作例を新規構築する際に適用する。利用者が保存した図面の読み込み時には、機関の大きさや配置を自動で変更しない。

## 生成と検証

現行28艦の結果は[作例の配置・機関・電力監査](benchmarks/capital-examples-energy-refit.json)に記録する。新規の作例構築、保存済み図面の現行計算による再検証、既存図面への現行機関設計の適用を区別して記録し、再検証を新たな作例構築と称することはしない。以前の[マンデイターII武装監査](benchmarks/mandator-battery-layout-refit.json)と[9作例の機関監査](benchmarks/example-engine-acceleration-refit.json)は、それぞれ当時の図面・計算元の記録として保持する。

最高速度のMGLTと加速度は別に扱い、[速度の参照表](reference-sublight-speeds.md)で公表値と計算上の仮定を区別する。
