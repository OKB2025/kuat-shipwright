# 装甲板の模様の廃止（v24）

ユーザーの指定で、装甲板（部品の「装甲板」）を模様のない一様な明るさで描くようにした。板の継ぎ目や点検口の模様が、不自然な見た目になるためである。色は塗装色のままである。

- 装甲板の部品は、模様のない専用のテクスチャ（`T.plain`）で描く（`MESH_TEX.plate = 'plain'`）。
- 船体・構造物・表面装甲の外観（装甲の印が付いた面の装甲スキン）は、以前のまま変えない。
- 窓の明かり、機械室のテクスチャ、参照モデル、太陽電池翼など、ほかの材質も変えない。
- 描画だけの変更なので、設計図・性能・作例のデータは変わらない（`js/gfx.js`）。

v24 の途中では、装甲の印が付いた面すべてを一様な明るさにしていた。この変更で船体の外観のスキンまで消えたため、装甲板の部品だけを一様にする形に戻した。

分離主義艦の測った構造物は、船体構造物と同じ描き方にした（[分離主義艦艇の組み直し](cis-stl-rebuild.md)）。
