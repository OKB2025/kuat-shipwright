# 装甲面の模様の廃止（v24）

ユーザーの指定で、装甲面に重ねていた装甲板の模様（不規則に組み合わせた板の継ぎ目の模様）を廃止した。不自然な見た目になるためである。

- 船体・構造物・表面装甲・装甲板のうち、装甲の印（頂点の材質番号 251）が付いた面は、模様のない一様な明るさ（0.815）で描く。色は塗装色のままである。
- 窓の明かり、機械室のテクスチャ、参照モデル、太陽電池翼など、装甲以外の材質は変えない。
- 描画だけの変更なので、設計図・性能・作例のデータは変わらない（`js/gfx.js` のシェーダー）。

分離主義艦の測った構造物は、船体構造物と同じ描き方にした（[分離主義艦艇の組み直し](cis-stl-rebuild.md)）。
