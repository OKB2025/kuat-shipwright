# 作例艦の戦闘性能キャッシュの更新

`data/fleet.js` の作例一覧は、以前のモデルで計算した艦隊用プロフィールを持っています。点防御を両用ターボレーザーへ変更すると、砲の役割だけでなく、砲火力・対空能力・給電・蓄電・熱・装備寸法に依存する値も更新する必要があります。

Core が生成するプロフィールへ `profileVersion` を記録し、現在の `FLEET_PROFILE_VERSION` と比較します。古い作例は、艦隊の準備時と戦闘開始時に必要な艦種だけを、既存の Worker の `fleet` 要求で再計算します。選んでいない任務群の艦種を一括で再生成せず、搭載艦は出撃に必要な艦種へ含めます。進行中の同じ要求は共有し、更新済みなら再計算しません。

カスタム戦闘・航行チュートリアル・任務の艦隊戦は、必要な古い作例の更新が終わってから世界を作ります。失敗した場合は戦闘を開始せず、任務の時刻や艦隊位置も進めません。再度の出撃操作で再試行できます。更新が不要な艦隊は、従来どおり直ちに開始します。

自作・保存済み設計のプロフィールは、この作例キャッシュの判定で無効にしません。既存の設計図・編成・搭載機プリセットと陣営・塗装の設定は保持し、`data/fleet.js` の古い計算結果に新しい版番号だけを付ける処理は行いません。

`tests/fleet-profile-refresh.cjs` は、要求の共有、必要な艦種だけの更新、搭載艦、更新失敗と再試行、三つの戦闘入口での待機、更新済み艦隊の即時開始を確認します。
