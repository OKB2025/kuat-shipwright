# 175TT・720TT砲塔の写真基準

新しい9モデルは、ISDに搭載された175TT砲塔の写真と、既存の40TT×8の40m取付領域を比較して寸法を決める。出力比の立方根で砲塔を拡大しない。元画像9枚は `assets/source/capital-turret-reference-1.jpg` ～ `9.jpg` に変更せず保存し、画像寸法・SHA-256・読取点を[測定記録](../assets/source/capital-turret-photo-measurements.json)へ記載する。

| 系列 | 全長×全高×全幅 | 寸法の扱い |
| --- | --- | --- |
| 175TT 2・3・4連装 | 60×16.5×45m | 共通の外形。門数によって砲基部の幅と正面の絞りを変える |
| ボール型4種 | 44.5×36×36m | 球径36mと砲口の最前面を共通にする |
| 720TT×2 | 90×24.75×67.5m | 175TTの形状を1.5倍にした寸法 |

175TT系列は2枚目の搭載状態を優先する。既存1600m ISD設計の砲塔列は62.36m間隔で、画像の取付中心を約 `(105,235)`、`(243,219)`、`(390,213)`、`(533,201)` と読むと、隣接中心間の投影距離は平均143.18pxになる。この方向の換算は約0.436m/px。中央の2基について、長い砲身と下の取付台を除いた本体・砲基部の投影幅は約57.0mと59.2mになる。

この搭載状態と「175TTの通常連装砲を40TT×8より大きくする」というユーザーの指定から、175TTの共通外形を60×16.5×45mへ校正する。写真は斜視なので、上記投影幅をそのまま三次元の全長・全幅とは扱わない。取付中心には5px、砲室の端には6pxの読取り幅を持たせ、遠近・向きによる15%の幅も別に記録する。720TT連装は、この175TT形状を1.5倍にする。

ボール型は1枚目の独立した球体の輪郭を基準にする。同画像の40m円盤について、ほぼ長径に当たる `(647,414)` と `(714,405)` を読む。間隔は67.60px、換算値は約0.592m/px。最も輪郭を読みやすい720TT単装の球体が約61pxで、換算すると約36.1mになる。共通の球径は36mとした。残る3種の球面の見える直径も、読取り・向きの不確かさを含めてこの大きさに収まる。

1枚目では異なる列に遠近差がある。角形175TTの絶対寸法については、画面全体を同じ縮尺だとした旧解釈を失効させ、搭載状態の2枚目を優先する。旧読取点は測定記録に残すが、角形砲塔の寸法テストへ使わない。比較用に記録した平面方向26度も作業上の近似であり、カメラ位置を三次元的に復元した値ではない。球体には15%の向き・輪郭判読幅と3pxの読取り幅を置く。

175TTターボレーザーの砲身は70TT系列の段付き形状を基に、校正後の全長26.25m・主部直径1.65mを設計値とする。イオン砲も全長は同じで、根元と先端の径は後述の太い先細形状に従う。720TTはその1.5倍で、全長39.375m・主部直径2.475m。砲基部に隠れる根元や砲口内部の奥行きは、写真から直接測れないため、実測値とは記載しない。ボール型は球径と砲口位置を変えず、大きくした砲身の根元を球内へ深く収める。

四連装175TTの砲基部と本体の幅の比は、既存70TT×3の18m÷24m＝0.75を基準にする。二・三連装はさらに砲基部を狭くし、正面の装甲がそこへ自然につながる形を取る。IS戦車風の潰れたお椀型は175TTイオン連装砲。通常175TT連装砲は角形で、追加された赤い技術図（5枚目）の機構・くぼんだ上部・後部の吸排気ハウジングを参考にする。5枚目は形状の製作資料で、寸法の基準には使わない。

2枚目で「一番左」と指定されたイオン砲塔は、3枚目で艦首が右にあることと合わせ、最も艦尾寄りの取付位置と解釈する。ゲームの艦首方向が増加する座標では、4基のうち最小Xの位置（index 0）である。2枚目の切り抜き単独には艦首の明確な印がないため、この方向づけは画像間の推定として記録する。

模型の下に見える円筒や、720TT×2の下の広い八角形の展示基部は、上記砲塔寸法へ含めない。ボール型は球面全体が旋回・俯仰し、球の下側約3分の1を取り付け面に埋め込む。

追加の6枚目は175TTイオン連装の前後に長い楕円形と前へ出た砲基部、7枚目はDBY-827と175TT連装・四連装の機構を確認する形状資料。絶対寸法の基準には使わない。

8枚目とユーザーの明示的な訂正を優先し、175TT連装の砲基部は左右の駆動輪を含めて本体最大幅45mの半分以下にする。砲室の上面は閉じた装甲面で、その上に機器を載せる。以前の広い砲基部・中央の開放ピットという解釈は失効。設計上の砲基部外殻幅は連装18m、三連装25.875m、四連装33.75mとし、連装の完全な可動基部は22.5m以下を検証する。

9枚目のイオン砲身拡大と指定に従い、イオン砲は太い付け根から細い先端へ絞る。同口径TL基準に対する設計半径比は根元2.2倍・先端主部1.25倍。平行な寸胴型とした旧解釈は使わない。これらの係数や内部寸法は写真からの厳密な三次元測定値ではなく、指定された意匠を形にする設計値である。

10枚目の正面上部の斜面は[別の製作資料](../assets/source/capital-turret-front-bevel-reference.json)へ原本と赤線の読取点を記録する。全体寸法の基準は変更せず、正面と左右の前寄りの面を屋根側ほど後退させる。
