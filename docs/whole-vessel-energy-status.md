# 全艦エネルギーモデルの作業状況

このブランチは作業途中であり、全艦作例の更新が完了したリリースではない。

給電線の詳細モデル廃止は実装・検証済み。[電源点と距離による給電](numerical-electrical-distribution.md)を機関・武装・シールド・冷却設備などに適用し、給電線の形状、経路探索、占有容積、質量、費用、独立した損傷パーツを生成しない。実受電、全艦蓄熱、イオン、燃料、直線の動力伝達路を含む関連テスト124件が通過している。

[実ブラウザ検証](benchmarks/numerical-electrical-distribution-browser.json)では、保存済みISD-IIを実際のWorkerで読み込み、給電線が生成されないこと、7本の動力伝達路が直線であること、7基すべてのノズルが公試で正の推力を出すことを確認した。これは保存図面の再計算であり、全艦の新規構築を検証したものではない。

[航空機の校正](benchmarks/whole-vessel-heat-calibration.json)は23機種・69条件を各600秒、被弾なしで再計算済み。停電・熱損傷・燃料の過剰消費はなく、許容蓄熱量は `3.1931e13 J/kg`、最大蓄熱率は約69.305%。12機種の物理設計由来の機体カタログも更新済み。

未完了は、大型艦の実機関容積と内部機器の配置、直線路との干渉、作例全28艦の最終再計算・カタログ発行・公開状態からの継続操作検証。エグゼクター、ルクレハルク、レキューザントの大型型、オナガー、サブジュゲイターなどの配置・支持能力の調整と監査が残っている。`data/fleet.js` と全艦の図面アーカイブを現行モデルで検証・発行し終えるまで、作例全体の更新を完了とは扱わない。
