# 全艦のエネルギー・蓄熱モデル

計算単位は J、W、kg、秒。機関の定格入力は受電上限であり、効率を決める負荷は実受電を通常入力 `P₀=3.4e17 V` で割った値とする。効率は `0.95 / (1+0.05 max(0,P/P₀−1))`、有効出力は `ηP`、機関発熱は `P−ηP`。標準機関の推力は有効出力を `1.9e9 W/N` で割る。構造・慣性補償の限界は、余分な入力を受け取る前に推進要求へ適用する。

器材の置き方は種類ごとに固定し、内蔵・一部露出・露出を切り替えるメニューを廃止する。内蔵器材は船内へ、武装・構造物・ノズル・外装型エンジンは外面へ配置する。ノズルは一つのカタログ項目とし、ベル型・汎用型の外見を選ぶ。機関本体の寸法・定格入力とは独立して保存する。

内蔵型高エネルギー散逸装置は「熱エネルギー変換装置」に改名する。単体の通常放熱装置は廃止し、旧図面の該当装置と接続は読み込み時に除去する。主翼・パネルの放熱機能は継続する。

炉から機関への配電は自動接続する。独立した推進配電区画は配置しない。旧図面の該当区画は読み込み時に外し、自動接続へ移行する。配電は他の器材と同じ内部配線として自動計算し、独立した立体区画としての配置・衝突判定は行わない。容量に応じた等価配線量・質量・費用は計上する。配電効率は接続端点間の距離 L に対して `exp(−1e−5 L)`。送電と受電の差をすべて発熱として計上する。機関からノズルまでの動力伝達経路は別の実経路である。

蓄熱容量は全艦質量に比例し、全熱源で一つを共有する。

`Q限界 = 全艦質量kg × 2.8017e13 J/kg`

[600秒の校正結果](benchmarks/whole-vessel-heat-calibration.json)は、設計図のある12機種と価格付き設備推定による11機種の計23機種を対象とする。通常航行、標準戦闘、シールド半充填からの標準戦闘をそれぞれ600秒、被弾なしで実行した。実際の機関受電、シールド再充填、武装電力、レーザーガス、Sフォイル、有限の冷却給電・排熱を使用する。最も厳しいケースはVウイングの半充填開始戦闘で69.306%。係数は70%到達に必要な最小値へ約1%の余裕を加えた値である。再実行は `node scripts/calibrate-ship-heat.cjs --output /tmp/heat-calibration.json`。

全艦の蓄熱率70%から安全弁が作動し、100%直前で出力上限は60%まで直線的に下がる。到達した最も低い上限を保持する。100%では全艦の電源を即時遮断する。冷却だけでは出力損傷は戻らない。既存の補給体系の修理費用・補給速度を使い、熱損傷の修理が完了すると上限が戻る。修理は残熱を消さない。

停電中は乗員充足率 c に対して毎秒 `c/300` の復旧作業を進める。定員充足で300秒、半数で600秒、乗員ゼロでは進まない。作業完了と蓄熱90%以下をともに満たすと再起動し、それまでの出力損傷は引き継ぐ。

イオン着弾前のシールド残量を S、着弾量を E とすると、阻止量は `B=min(E,S)`。`0.95B` を艦外へ放出し、シールドを `0.05B` 消費する。`max(0,E−S)` だけを全艦蓄熱に加える。イオンには独立した一時保持や局所過負荷タイマーを使わない。通常砲撃は艦外82%・シールド一時保持12%・艦内発熱6%を維持する。シールド運転発熱は実受電の30%。

サブジュゲイターのパルスは艦外へ戻された分と未命中分を保持し、次の艦へ進む。各命中で減る量は `0.05B+max(0,E−S)`。射撃用のTT表記は既存の境界でJへ変換する。

全艦蓄熱から引くのは、実在する排熱設備が実際に艦外へ排出したエネルギーのみ。艦内の熱移動は蓄熱を減らさない。冷却装置自身の受電、送電損失、炉の変換損失も発熱する。冷却用の電力予約は、実際に使うまで発熱・燃料消費へ計上しない。

燃料は実発電と同じ炉変換損失から消費量を求める。既存の架空燃料のエネルギー密度 `1.2e25 J/m³` は保持する。推進排気の放射は受電ではなく有効推進出力に比例する。航行試験の自艦・随伴艦・艦隊・航空機でも同じ蓄熱・給電計算を使う。
