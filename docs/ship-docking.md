# 艦船の入渠（v26）

ユーザー決定（2026-11-17）：「赤道トレンチは艦船ドックで実際に船が入って補給が受けられるように」「ドックを別パーツにするのではなく、航空機の格納庫と同じ扱い」、補給は「戦略マップの補給と同じ＋燃料・充電」。

- ドックは格納庫です。艦は、開口部（幅と高さ）と区画（全長）に収まる格納庫口（`p.mouths`、区画の大きさ `bs`）から入ります（`dockState`、`dockFits`）。
- 入渠命令（`order.type='dock'`）の艦は口の外の点へ向かい、口から入り、区画内で母艦との相対速度が `DOCK.speed`（60 m/s）以下になると入渠します。以後は母艦と一緒に動き、補給を受けます（`dockStep`、`dockResupplyStep`）。
- 補給：ミサイル、武装の蓄電、燃料、乗員、ハイパードライブの充電（時定数 60 s）、モジュール・区画・装甲・熱損傷の修理（時定数 180 s）。
- 別の命令を受けると出渠します。
- 公試では、操艦中の艦が味方の格納庫内で低速・スロットル停止になると入渠し、推力を上げると出渠します。消耗した僚艦（`dockNeed` ≥ 0.35）は自分で入渠に向かいます。
- デス・スターは赤道トレンチの手前側に艦船用格納庫を 3 つ持ちます（奥行 2.5 km、高さ 1.8 km、長さ 3 km）。

未実装：戦略マップの入渠命令、区画の定員と順番待ち、出入りの経路（レール）、艦の向きを考えた収まり判定。設計案は次の PR で扱います。
