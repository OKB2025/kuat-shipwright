# 自動熱制御

全艦の蓄熱が出力制限の始まる量（容量の70%）に近づくと、艦は自分で推力と砲の充電を絞る。熱損傷による出力上限の低下に入る前に、発熱を散逸量まで下げるための仕組みである。

| 蓄熱 | 推力 | 砲の充電 |
| ---: | ---: | ---: |
| 55%以下 | 100% | 100% |
| 55〜68% | 100%から10%へ直線的に低下 | 100%から0%へ直線的に低下 |
| 68%以上 | 10% | 0% |

- 砲の充電を絞ると、充電に時間がかかり、射撃の間隔が延びる。充電装置に蓄えた分は撃てる。
- シールドと生活設備の給電は絞らない。
- 散逸装置が蓄熱を下げると、同じ曲線で元の出力に戻る。
- 操縦中の旗艦にも同じ制御がかかる。

戦闘画面の自艦情報と航行画面の艦情報に、絞っている間だけ「熱制御中 · 推力 n% · 砲の充電 n%」と表示する。

閾値は `HEAT.governStart`（0.55）、`HEAT.governEnd`（0.68）、`HEAT.governEngineFloor`（0.1）で、計算は `heatGovernor(u)` にある。出力制限の始まり（`HEAT.limitAt`、0.7）、緊急停止、熱損傷の扱いは変えていない。
