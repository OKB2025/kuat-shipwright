# 指定4艦の作例兵装

現行の独立した砲塔モデルと計算に合わせて更新した配置。表の数は砲塔の基数で、連装数は1基あたりの砲身数を示す。PDは全て左右にレーザーを備える20 GTの2連装。

| 作例 | 対艦砲・イオン砲 | 2連装PD |
| --- | --- | --- |
| インペリアルI級 (`imperial`) | 175 TT 2連装6基、175 TT 2連装イオン2基、70 TT 4連装2基、40 TT 3連装9基 | 20基 |
| ヴェネター級 (`venator`) | 70 TT 2連装8基、70TT×2 舷側2基、200 GT単装10基 | 28基 |
| ネビュロンB (`nebulonb`) | 200 GT 2連装3基 | 5基 |
| アクラメイター級 (`acclamator`) | 200 GT 4連装12基 | 12基 |

## 配置

座標の単位はm。`x`は艦尾から艦首へ、`z`は中心線から右舷へ向かう距離。`±z`は左右の対を表す。高さは各座標にある実際の船体面に合わせる。

- **インペリアルI級:** 主砲座8基はLarsHのモデルの砲塔中心に置く。`x=292.8`の左右がイオン砲、`x=353.9, 414.9, 477.7`の左右が175 TT砲で、いずれも`z=±255.7`。70 TT 4連装は`x=700`の左右トレンチ壁に各1基。40 TT 3連装は中心線の`x=752, 780`（前部甲板の中央稜線上）と`x=845`、`(x, |z|)=(650,82), (930,105), (1160,58)`の左右。PDは上面12基、下面8基に分散。
- **ヴェネター級:** 艦橋基部の70 TT砲8基は実測砲座を保持。`x=763`の左右トレンチ壁の2基は、ユーザーの指定で70TT×2 舷側（`venSide70`）とした。200 GT単装は`x=620, 710, 850, 940, 1030`の左右トレンチ内に各1基。PDは上面16基、下面12基。左舷前方の70 TT砲は待機時の向きを25度外側へ回し、隣接する防護壁から砲口を離した。
- **ネビュロンB:** 200 GT 2連装は中心線上の`x=27, 235, 278`に配置。PDは下面の`(x, |z|)=(205,15), (265,12)`の左右と、艦尾側の`(14,0)`に配置。
- **アクラメイター級:** 200 GT 4連装は`(x, |z|)=(200,118), (245,118), (290,104), (340,96), (390,84), (440,74)`の左右。PDはブリム上面の`x=200, 282, 364, 446, 528, 610`に左右各6基を分散した。

既存の発射管とトラクタービームも保持する。発射管はヴェネターとアクラメイターに各4基、トラクタービームはインペリアルI級10基、ヴェネター6基、ネビュロンB2基。

## ヴェネターの充電設備と航空甲板

トレンチ内の200 GT単装砲は、砲室に収まる分に加えて、1基あたり約3.095 m³の艦内充電装置を必要とする。この実物の充電装置と周囲0.15 mの余裕を確保するため、隣接する格納庫・整備甲板を上下と前後左右に分割した。充電装置に譲った部分以外の甲板は残り、格納容量も残った実際の形状から計算する。

全4艦119基について、砲座、砲口の船体外への露出、砲同士の間隔、各砲身の発射口、実物の充電装置による一斉射分の充電を回帰テストで検証する。
