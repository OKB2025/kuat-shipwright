# パワーセルの廃止

区画パーツ「パワーセル」（`battery`）を廃止した。熱の面で有利すぎたためである。蓄電の役割は、各砲塔がもつ充電装置が担う。

- 部品一覧から「パワーセル」を外した。
- 戦闘で使っていた艦全体の蓄電（`reserve`、戦闘画面の「蓄電」バー）は無くなった。シールドは炉からの給電で再生し、砲は各砲塔の充電装置に蓄えた電力で撃つ。
- 武装への配電は反応炉から直接行う。配電路の長さは、反応炉から砲までの距離で決まる。

## 既存の設計と作例

パワーセルを参照していた箇所は、熱エネルギー変換装置（`hdis`）に置き換えた。パワーセルが無くなってもエラーは出ない。

- 保存済みの設計を読み込むと、パワーセルの区画は同じID・寸法・接続のまま熱エネルギー変換装置になる。読み込み時に「パワーセル n 区画を熱エネルギー変換装置に置き換えました」と表示する。
- 作例を組み立てる処理がパワーセルを置く箇所でも、同じIDの熱エネルギー変換装置になる。後続の部品のIDは変わらない。
- 艦の系統を組み直す処理（`constructShipSystems`）の主配電の起点は、熱エネルギー変換装置になった。
