# 標準ファイターの内部再構築

標準12機種を、ノズル容積から推力を出していた内部配置から、実給電で駆動する機関・反応炉・配電へ組み直した。砲、機体の測定外形、ノズルの出口位置は維持する。公式の内部設計図の再現ではなく、設計局の共通部品モデルに収まるゲーム用の設計である。

- 小さい炉で兵装を優先すると TIE や Vulture の推進に電力が残らなかったため、機体内の実容積を使う反応炉へ変更した。Hyena、Torrent、V-wing も機関・兵装用の炉を再配置・増強した。
- 機関本体の寸法、受入定格、通常カタログの有限な入力密度を明示した。新しい機関の互換冷却はゼロで、既存の機体・翼の熱網を使う。
- 炉から機関、砲、シールドへの有限容量の配電を明示し、一方の炉に余裕があっても反対側の機関へ供給できない配置を改めた。
- X-wing は船体より後ろへ張り出す推進管の質量を支える縦通支持材を追加した。管内の支持材を翼の付け根につなぎ、Sフォイルと一緒に動かす。
- 操縦、航法、照準、生命維持、姿勢制御、着陸、レーザーガスは、重なりのない通常の部品として残す。

新規作例の組み立て時だけ、完成機体の質量から部品の入力定格を選定する。`computeStats` や戦闘時の加速度・速度に機種専用の倍率を加えない。保存済みのプレイヤー設計は再構築せず、部品の削除や定格変更もそのまま保持する。

|---|---:|---|
| ARC-170 | 3,551 G | 従来の作例のゲーム用仮定 |
| A-wing | 5,100 G | 公表加速度 |
| BTL-B | 3,000 G | 公表100 MGLTを設計局の換算へ適用 |
| Hyena | 2,250 G | 従来の作例のゲーム用仮定 |
| TIE/IN | 4,240 G | 公表加速度 |
| TIE/ln | 4,100 G | 公表加速度 |
| TIE/sa | 2,380 G | 公表加速度 |
| V-19 | 4,696 G | 従来の作例のゲーム用仮定 |
| Vulture | 3,600 G | ゲーム用仮定。共通換算で108 MGLT |
| V-wing | 5,200 G | 公表加速度 |
| X-wing | 3,700 G | 公表加速度 |
| Z-95 | 3,330 G | ゲーム用仮定。X-wingの90% |

最大定格、現在の実加速、ゲーム上の速度上限を区別する。設計画面の標準戦闘プレビューは兵装優先・推進35%なので、健全な機体の実加速は上表の35%になる。最高速度の計画値には最大定格と構造・慣性制約を使う。

検証は [fighter-interiors.json](benchmarks/fighter-interiors.json) に改修前 `9beee00` との比較を記録する。全12機種で部品・機関経路の重なり、定格容量、保存再読込、全推進・全兵装・全シールドを同時に要求する30秒の運転を確認する。熱の検証条件は冷間・無損傷・Sフォイル展開・0.5秒刻みであり、熱平衡が解けた持続定格という主張ではない。

再実行:

```sh
node --test tests/fighter-interiors.cjs tests/craft-example-systems.cjs
node scripts/benchmark-fighter-interiors.cjs
```
