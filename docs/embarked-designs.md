# 自作の艦・機体を航空隊で使う

艦船と航空機は同じ設計図・部品・兵装を使います。艦種による部品の使用制限はなく、艦種は寸法や初期設定の目安です。スターファイター以外として設計した艦も、母艦の格納庫に入れば航空隊へ編成できます。

艦の設計図には格納庫・発艦口・兵員枠などの容量だけを保存し、実際の艦載機・搭載艦・陸戦部隊は艦隊編成で指定します。作例や古い艦の設計図にあった搭載内容は、設計図を読み込んでも自動で復活しません。新しく編成へ追加した艦の搭載内容は空で、既存の編成に明示保存された搭載内容は維持します。編成の「お任せ」を使う場合も、その編成にだけ搭載内容が設定されます。

1. 搭載したい艦・機体を設計して保存します。設計中の艦をそのまま選ぶこともできます。
2. 航行の「編成」で母艦の「航空」を開きます。
3. 「搭載する機種・艦種」の「設計した機体・小型艦」から設計を選び、「搭載を追加」を押します。
4. 機数、飛行団番号、飛行隊番号を設定します。同じ母艦・飛行団・飛行隊番号の中隊が一つの飛行隊になります。
5. 搭載・発艦の表示を確認して出撃します。格納庫の容量と内寸、接続されたハッチの開口を満たす機数が発艦します。

新しい自作機の中隊は1機から始まります。機数を増やすと、必要な格納容量・費用・操縦士や乗員も増えます。艦の寸法と搭載兵装、推進・動力などの設計計算から、艦載運用時の性能を算出します。航空隊での戦闘は既存の中隊単位の計算を使います。

中隊の「中隊をコピー」で1中隊を、飛行隊の見出しにある「飛行隊をコピー」で配下の全中隊を複製できます。機種・機数・兵装・その時点の設計図を引き継ぎ、コピーした飛行隊には未使用の飛行隊番号を割り当てます。コピー分も格納容量と費用へ加算します。

戦闘中は「飛行隊」一覧から、それぞれの飛行隊へ攻撃・護衛・哨戒・帰還などを命令できます。他の飛行隊の命令はそのまま維持します。

編成には、その時点の設計図と性能を保存します。元の設計を更新・削除しても、編成済みの機体は変わりません。新しい設計に入れ替える場合は、中隊の「機種・設計」で設計をもう一度選びます。保存した編成やシナリオを読み込んだ場合も、その時点のモデルで飛行します。

既存の「艦艇」から積んだ搭載艦は、これまでどおり独立した艦として発進します。航空隊へ入れたい場合は「設計した機体・小型艦」から追加してください。古い性能のみの設計機データも読み込めますが、元の設計が失われた場合のモデル復元には、新しい形式での選び直しが必要です。
