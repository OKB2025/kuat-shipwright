# アーキテンスの機関配置と1,800G

アーキテンスの最大加速度をユーザー指定の1,800Gとし、3つのノズルの膨らみへ、それぞれ独立した機関本体を配置する。1基の共通機関から3ノズルへ送る従来の作例構成を変更する。

既存の各ポッドは直径約32mで、X14～40m付近に太い部分があり、前方へテーパーしている。各機関は直径29.5mを基準に、その内側へ置く。長さは機関・支持・冷却・配電と伝達路を含む完成質量から調整する。機関の通常入力密度 `3.4e17 W/m³` と旧来の推力密度 `1.7e8 N/m³` を維持し、定格の密度を増やして目標へ合わせない。

各機関は近くの専用反応炉から給電し、不足分は既存の主反応炉から受ける。元の艦全体の発電量を維持し、他のポッドの専用炉へ先に頼る配電を避ける。配電路の距離による損失・発熱・有限容量は通常どおり計算し、機関から対応ノズルへの短い動力伝達路を表示する。

外装ポッド、ノズルの外観と開口位置、構造物と武装を保つ。新規作例の構築に適用し、保存済みの設計を読み込む際には機関の寸法や所有関係を上書きしない。

[新規構築と物理監査](benchmarks/example-engine-acceleration-refit.json) と [機関配置テスト](../tests/arquitens-engine-layout.cjs) は、各ポッドに1基ずつあること、機関全体がポッド内に収まること、通常容積による最大加速、元の外装・発電量の保持を確認する。

[実画面の検証](benchmarks/arquitens-1800g-browser.json)は、タイトルから実際の作例を選び、Workerによる新規構築、最大1,800Gの表示、3つの機関本体・ノズル・動力伝達路、公開済み構築図面との同一性を確認する。各機関は専用補助炉と共通主炉の2系統から受電するため、配電路は計6本となる。端点と要求容量を独立した物理監査に照合し、配電路のメッシュが表示されないことも検査する。
