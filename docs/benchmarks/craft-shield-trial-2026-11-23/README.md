# 航空機のシールドを強くする試験（KS_CRAFT_SHIELD、2026-11-23）

ユーザー：「航空機のシールドをもう少しだけ強くしてみて」。試験用の切り替え `KS_CRAFT_SHIELD=k` は全長 20 m 以下の機体のシールド（容量・回復・発熱）を k 倍にする。ゲーム本体は使わない。
