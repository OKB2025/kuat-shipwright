## TIE/ln・TIE/in の浮き・断線・熱経路

断線 1 系統と熱輸送路 8 本は、どちらも腹部パイロン #430 が浮いているために起きている（パイロンへの給電線と、パイロンから熱エネルギー変換装置 8 基への熱輸送路）。
パイロンは y=1.99、魚雷発射管 #431 の下面（1.98）の 1 cm 上にある。その下面は操縦ポッドの外皮（1.978）より 1.5 mm 内側に埋まっている。
- 配置の解決（エディターが使う `solveFitPlacement`）は発射管 #431 に付いていると判定する。
- 取り付けの検査（`remount`・性能計算）は一番外側の面だけを見るため、ポッドの外皮から 1.2 cm 埋まっていると判定し、浮きにする。
- ファイルのパイロンには `host` がなく、ホスト #431 を足しても浮きのまま。y=1.978 以下に下げるとポッドに付き、警告 3 件が消える（gap3.cjs）。
判定：配置位置は 1 cm ほどずれた実際の問題だが、エディターと検査の判定が食い違っているのはこちら側の不具合。空戦試験には y=1.978 に下げた写しを使った。
