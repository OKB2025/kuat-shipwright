## 近接炸裂でシールドが働く規則を足したあと（with-proximity-shield/）

ユーザー：「直撃ではなく近接で作動するならシールドは動作していいのでは」。命中のうち近接炸裂（機体の外、信管の内）は 79 発中 19（X ウイング 対 TIE/D）、23 中 4、33 中 4、5 中 3、2 中 0。誘導弾は 0.25 秒ごとの経路で機体の中心へ向かうので、命中の大半は直撃のまま。勝敗はほぼ同じ（X ウイング 対 TIE/D は 0・20・0）。
