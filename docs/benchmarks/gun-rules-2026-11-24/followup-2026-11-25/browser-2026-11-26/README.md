# ブラウザ確認（2026-11-26、PR #127）

`python3 -m http.server 8765 --bind 127.0.0.1` で配信し、`node check.cjs http://127.0.0.1:8765/`（Playwright、Chromium、1280 × 800）。結果は `report.json`。画面の画像はスクラッチパッドに出した（リポジトリには入れていない）。

## 見つけて直した不具合

- **画面が起動しなかった**：TIE アヴェンジャー試作機の作例に全長が無く、タイトル画面の作例一覧を作るところ（`fLen(undefined)`）で起動の処理が止まっていた。この作例を足したコミット（`98114896`、2026-11-25）からこのブランチの画面は起動していなかった。全長 13.41 m（設計の x 方向の実寸）を入れ、全長が無くても「—」と出して止まらないようにした。単体テストは画面の起動を通らないので検出できていなかった。

## 確認できたこと

- 起動し、作例 3 機が開く：B ウイング 18.552 t・2,513 G（警告なし）、トライファイター 8.316 t・3,855 G（警告なし）、X ウイング 29.675 t・4,515 G（反応物供給 85% の警告。変更前からある）。砲はすべて `claser` で、浮いているものは無い。
- 設置済みのレーザーを選ぶと情報ウィンドウに「固定式レーザー砲、3.500 × 0.150 × 0.150 m、136.48 kt」と出て、「編集」で編集パネルが開く。レーザーの欄はパネルの最上部（1 番目）。
- スライダー：口径 0.02〜0.4 m、長さ 0.2〜10 m、連射 0.2〜10 発/秒。ノズルは「そのまま／追尾ノズル（X ウイング型）」。
- 口径を 0.2 m にすると 1 発 371.4 kt、砲 1 門 0.676 t（中空の筒）、本体の太さ 0.267 m、機体の質量 29.67 → 30.62 t（対の 2 門が変わる）、砲は取り付いたまま。
- 追尾ノズルにすると連射の上限が 1 発/秒になり、命中の表示が「100%（±3° 追尾）」になる。
- 書き出した設計に `craftLaserRule: 2` が入り、装備の種類は `claser` と `ctorp` だけ。
