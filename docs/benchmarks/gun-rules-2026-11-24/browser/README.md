## 追加の確認（2026-11-25、候補 520bcf0 の作業ツリー、Chromium・ソフトウェア描画）

### エンブレムの移動バー（`emblem.cjs` → `emblem.json`、`emblem-added.png`、`emblem-moved.png`、`emblem-reload.png`）

- 実行：`node docs/benchmarks/gun-rules-2026-11-24/browser/emblem.cjs <root> <outdir>`。
- 手順：作例 CR-90 を開く → 船体構造物を選んで編集を開く → 「塗装」→「四角を追加」→ 船体をクリック → 移動バー（前後 X の ＋、刻みを 2.5 m に変更、上下 Y の −、左右 Z に数値 7.25 を入力）→ Ctrl+Z ×3 → Ctrl+Shift+Z ×3 → 編集を確定 → 下書き → ページ再読込。
- 結果：
  - 追加：クリックした面に 1 個追加され、選択された。0° の絵の上は艦の上（面の法線 (0, 0.12, 0.99) に対し上 (0, 0.99, −0.12)）。
  - 移動バー：3 行（X・Y・Z に − と ＋）と刻みの欄が出る。X ＋ で 77.489 → 78.689（刻み 1.2 m ＝ 大きさ 12 m の 1 割）、刻みを 2.5 にして Y − で 15.527 → 13.027、Z に 7.25 を入力して 6.343 → 7.25。入力欄の表示も同じ値に更新。
  - Undo は 1 操作ごとに 1 段（Z → Y → X の順に戻る）、Redo で 3 段とも戻る。
  - 編集を確定する前は下書きにエンブレムは入らず（0 個）、確定の後は下書き（`yard.draft3`）に位置・向きごと入る。再読込の後に再開した設計にも同じ位置・向きで残る。ページエラー 0 件。
- 注意：塗装の画面には「構造物を選ぶ → 編集 → 塗装」で入る。編集を開いていない状態のクリックは部品の調べるタップになり、エンブレムは置かれない（仕様どおり）。

### 機体レーザーの新規配置（配置前スライダー、`claser-new.cjs` → `claser-new.json`、`claser-new-drawer.png`、`claser-new-placed.png`）

### 旧保存のエンブレムの向き（計算だけ。画面では未確認）

- 2026-11-24 に 0° の基準を変えた（`decalFrame`）。旧：幅の向き u ＝ 艦の前後を面に投影、上 v ＝ n × u。新：上 v ＝ 艦の上（甲板・船底では艦首）を面に投影、u ＝ v × n。
- 同じ保存値（rot）での絵の上の向きの違い：右舷の壁（n ＝ +Z）は同じ（+Y）。左舷の壁（n ＝ −Z）は旧 −Y → 新 +Y（180° 回る）。上甲板（n ＝ +Y）は旧 −Z → 新 +X（90° 回る）。船底（n ＝ −Y）は旧 +Z → 新 +X（90° 回る）。
- 移行は入れていない（保存データに旧・新の印が無いので、区別するには印の追加が要る）。入れるかはユーザーの判断待ち。
