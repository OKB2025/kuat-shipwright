# 新しい砲での艦隊戦とシールドの摩耗（2026-11-24）

scripts/sim-fleet-air.cjs（反乱軍 MC75・MC80・ネビュロン B×2・CR-90 対 ISD×2、80 km、900 s まで）を、今のコードで組み立て直した性能値で流した（sim.cjs。性能値は profile-*.json に一時保存、リポジトリには入れていない）。

| 条件（艦だけ） | 結果 |
| --- | --- |
| main（古い砲、main-ships-only.txt） | 497 s で反乱軍全滅 |
| 新しい砲（ships-only.txt） | 900 s で決着せず（MC80 645 s、MC75 無傷） |
| 削り値 debit 0.5／0.75／1 | 決着せず（MC80 584／376／342 s） |
| 回復 returnK 3.25／2／1 | 決着せず（MC80 646／476／266 s） |
| 摩耗 wear 0.025／0.032／0.04 | 764／596／514 s で反乱軍全滅 |

- 経過（diag.cjs）：張れているシールドは砲火をはじき、受けた量 × wear だけ最大容量が下がる。MC75 のシールドは debit・returnK によらず毎秒約 22 TT 減る（ISD 2 隻の砲火 約 1,750 TT/s × 0.0126）。新しい砲は 1 発の充電に 1 発 ×（1 + 砲身 ÷ 19 m）が要り、反応炉で賄える火力が古い砲の約 4 割。
- 採用：SHIELD_MODEL.wear 0.0126 → 0.04（514 s、古い砲の 497 s に近い）。
- 航空機あり（with-wings.txt、wear 0.0126・点防御の強化前）：3 回とも ISD 1 隻が 86 s で重力制御装置を失って墜落。原因は未切り分け。

## 採用値での確認（wear 0.04、点防御の命中 0.85、搭載機のレーザーはシールドへ。32c9b25）

- 艦だけ（final-ships-only.txt、2 回）：514 s・515 s で反乱軍全滅。
- 航空機あり（final-with-wings.txt、2 回）：1 回目は 128 s で ISD 2 隻とも「電源喪失」で反乱軍の勝ち、2 回目は 900 s で決着せず（ISD 1 隻が 86 s で電源喪失 → 墜落）。
- ISD が 86 s で落ちる経過（diag.cjs ISDLOG=1）：その瞬間のシールドは 23,584／23,808 TT（99%）で、区画の損失 0、機器 11〜16 個が停止、飛翔中のミサイル・魚雷 6〜9 発。シールドが張れたまま電源を失っているので、原因は航空レーザーではなく、シールドを通らずに艦に直接当たる魚雷・ミサイル（v24 の規則と PR #125 の魚雷の規則）。main でも同じかは未確認（ユーザー指示で main の航空機ありは流していない）。

## 物理レビュー後の再確認（1 発の充填 E×(1+c) を戦闘でも消費。7e727bb 以降）

物理レビューの指摘で、艦隊戦が 1 発につき E だけを消費していたのを、設計画面と同じ E×(1+砲身÷19 m) に直した。そのぶん反応炉で賄える火力がさらに減ったので、艦だけの戦いを流し直した。

| 条件（艦だけ、1 回ずつ） | 結果 |
| --- | --- |
| wear 0.04（charge-ships-only-wear0.04.txt） | 612 s で反乱軍全滅 |
| wear 0.05（charge-ships-only-wear0.05.txt） | 513 s で反乱軍全滅 |

- 採用：SHIELD_MODEL.wear 0.04 → 0.05（古い砲の 497 s、修正前の採用値の 514 s と同じ長さ）。
- 航空機ありは流し直していない。
