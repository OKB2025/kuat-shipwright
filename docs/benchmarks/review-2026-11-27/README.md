## 最終の対応（2026-11-27、cf5d348a 以降）

- **迎撃で無力化された弾**（ユーザー「推進剤が爆発して弾頭だけ飛んでくる」）
  - 1 発目の被弾で推力と誘導がなくなり、そのときの速さのまま直進する。弾頭の被害は満額。艦隊戦と戦略画面の両方で同じ。
  - 魚雷も、無力化された後は減速しない。
  - 寿命は、射程の終わりまで延ばす。
  - テスト：`tests/missile-single-release.cjs` の 10・11 番。10 番は変更前のコードでは失敗する。
- **装填表の質量**（ユーザー「揃える」）
  - 機体価格表にある、作例の設計の実測質量を使う。
    - 価格表の値は、computeStats(buildDesign) と完全に一致する（BTL-B 76.186 t、X ウイング 27.769 t）。
    - 一致の記録：`catalog-vs-design.txt`。
  - 戦略画面の母艦の積載量が変わる。12 機を載せた MC80 の例（変更前 → 変更後）：
    - X ウイング：275 → 338 t
    - Y ウイング：5 → 710 t
    - BTL-B：633 → 919 t
    - B ウイング：5 → 213 t
- **テストの期待値**（旧値と理由はテスト内に記録）
  - `point-defense-toggle-aircraft`：単発弾は丸ごとの被弾になったので、迎撃したことを期待命中数の記録（`m.pdShotAt`）で確かめる。
  - `runtime-foils-core`：S フォイル 1 枚あたりの構造物は 16 → 15、全体は 72 → 68、収納姿勢の部品は 18 → 17。
    - ユーザーの 11-27 改装（`xwing-refit-2026-11-27.json`）は 1 枚あたり 18（全体 80、収納姿勢 20）。ここから、フォイルのメンバーであるノズルの構造物 3 個（サプレッサー・カラー・アンテナ）を除いた。
