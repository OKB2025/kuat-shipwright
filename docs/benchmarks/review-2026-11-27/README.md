## 数値（`figures.cjs`、出力は `figures-32f766b0.txt`）

  - ユーザーの表 27.766 t との差 3 kg は、翼の補強・駆動の質量が機体の平均密度（質量 ÷ 体積）から決まるためです。ノズル部品は体積を持たず質量だけ増えるので、その分が翼の質量（`wingMass`）に乗ります。
