# レーザーに対する航空機の耐久（2026-11-23、現行の値）

tail.cjs：攻撃機が目標の真後ろ（150・300・600 m）につき、目標は直進（300 m/s）。シールドが破れた時刻と撃墜の時刻（3 回）。試験用の切り替えなし。作例はリモデル後。fields.log：シールド容量（TT）と火力（gunBest、TT/s）。
シールドは航空機の曲線（X ウイング 13.4 m で 3×10⁻⁶）、TIE/ln・TIE/in・Z-95・V-19 はシールドなし。

## ばらつきを狭めた（2026-11-23「ばらつき度を狭めて」）

航空機に当たる弾のうち、1 ステップの期待値が 1 発に満たないときの「当たる／当たらない」と、当たった弾が「パネル（翼）に当たる／機体へ抜ける」を、乱数で毎回決めるのをやめ、期待値を持ち越して 1 になるたびに当てる形にした（`u.shotAcc`・`u.panelAcc`、初期値は 0.3〜0.7 の乱数）。平均は同じで、ばらつきは 1 発ぶん以内になる。どのパネルに当たるか、機内のどの装置に当たるか（反応物燃料タンクの誘爆などを含む）は従来どおり乱数。

tail-narrow2.log（5 回、変更後）と tail.log（3 回、変更前）：
- シールドのある目標（X ウイング・A ウイング・TIE/D）はほぼ同じ秒数になった（TIE/ln → A ウイング 300 m：変更前 3.5〜8.0 秒 → 4.5〜4.8 秒）。
- シールドのない TIE（X ウイング → TIE/ln 300 m：2.3〜3.3 秒 → 3.5〜4.0 秒、5 回中 1 回だけ 0.5 秒）。残る外れ値は、最初に機体へ抜けた弾が反応物燃料タンクに当たって誘爆したもの。
