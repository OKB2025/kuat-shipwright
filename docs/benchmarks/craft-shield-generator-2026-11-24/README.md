# シールド補正を発生器の大きさから（2026-11-24）

ユーザー：「シールド性能の補正値は機体の長さではなくシールド発生器そのもののサイズから計算して」。

- js/core.js `fieldScale`：航空機の曲線（`CRAFT_SHIELD_EXP`）を、船体の長さではなく発生器の大きさに当たる長さ
  `refLen × ∛(発生器の体積 / refGenV)` で読む（`shieldGeneratorLength`）。`refGenV` は X ウイングのリモデルの発生器（直径 0.86 m、0.333 m³）で、
  X ウイングは今までどおり `refScale` 3e-6。体積は艦隊の単位プロファイルのシールド・局所シールドの装置（`modules` の `size`）の合計。
- 発生器の大きさで読むのは航空機（プロファイルの分類が `craft`、`craftUnit`）だけ。艦はすべての大きさで長さのまま（2026-11-23「艦は元のまま」）。物理レビューの指摘で、最初の版では 20〜100 m の艦（60 m・63.8 m・GR-75）も変わっていたのを直した。20〜100 m の混ぜ合わせの重みは船体の長さのまま。発生器の装置を持たない航空機のプロファイル（旧形式・表だけの機種）は長さを使う。
- 実戦の機体ユニット（fleetAirSetup で発艦した BTL-B）で、分類 `craft:true`、相当長 16.4 m、補正 5.24e-6 になることを確認（/tmp/ks-verify/20261124-remodel9/unitcls.cjs）。
- 注意（物理レビュー）：シールドの容量はもともと発生器の体積に比例するので、補正も体積から決まると、20 m 以下の機体の容量・回復は体積のほぼ 2 乗（V^1.98）に比例する。直径 2 倍で約 62 倍。
- 試験：tests/craft-shield-generator-scale.cjs。
