# ロックオン・照準内誘導・弾の飛び方の試験と近接信管 10 m（2026-11-23）

ユーザー：「レーダーロック段階で警報が鳴るようにする。ミサイルは当たるまで敵をカーソル内に入れないといけなくする…」「近接信管は10mに」。
- 試験用の切り替え：KS_MISSILE_LOCK=1（1 秒のロックで発射可、ロック開始で相手に警報、発射機が照準 15° 内に目標を保つ間だけ誘導）、KS_LOCK_REACT=1（警報で回避）、KS_ROUND_PROFILE=1（ミサイル 1,500 m・加速→減速→自爆、魚雷 2,000 m・機速+150 m/s から減速して停止・自爆）。
- 近接信管：MISSILE_FLIGHT.craftFuse を 40 m から 10 m に変更（ゲーム本体の値。fuse40/ は比較のため 40 m に戻した写しで実行）。
