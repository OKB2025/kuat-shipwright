## ビルダーと保存済みの設計の対応

- 保存済みの設計は `1a44d1d` のビルダーで作った。`1a44d1d` から現在までの `js/core.js` の差分は 2 行だけ（`shieldReceive` と `heatEvaluate`。`git diff 1a44d1d -U0 -- js/core.js`）で、マンデイター II のビルダー、`shipRefitInternalCores`、`buildDesign` の後処理は変わっていない。
- 画像は `scripts/browser-mandator-layout-saved.cjs` を出力先だけ変えた写しで描いた（`--draft --archive data/examples/mandator2/design.json.gz --phase draft-final`）。入力の JSON の SHA-256 は `ea133918…35fe7a1`、描画時の `js/core.js` は `e85c36f1…`（`1a44d1d` と同じ）。ラベルの「draft-final」はスクリプトの引数名で、下書きという意味ではない。
- `bottom-brightened.jpg`／`ventral-brightened.jpg` は、暗い下面の画像の明るさだけを上げたもの（ガンマ 0.45）。
- 設計画面（実際の Worker の読み込み経路）での統計と、`1da778b` との前後比較は PR の説明に記録する（前後比較の表は `docs/benchmarks/regeneration-2026-11-20/`）。
