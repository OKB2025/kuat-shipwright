# 大型ランチャーのセル間隔（2026-11-21、PR #122）

ユーザーの指示「セル間隔と数、並び列は編集可能に」（ヴィクトリー級のミサイル位置＝直径 13.4 m の円い蓋、前後 約 18.5 m・上下 14.9 m 間隔に合わせるため）。続く決定「蓋が丸いならそのままでいい」（セルは四角い箱と円い蓋のまま）、「間隔を広げた時も装甲を残さなくていい」（埋め込みの切り欠きは本体全体の箱 1 つ）。

- 大型セルだけ。列の間隔・段の間隔（セルの中心どうし）を別々に 12.1〜100 m。12.1 m（セルが接する、いままでの並び）が既定で、保存しない。
- 間隔を広げると本体の幅・高さだけが広がる（4 列 × 2 段・18.5 m／14.9 m で 67.6 m × 27 m）。弾数・質量・費用・電力はセル数で決まり変わらない。
- 既定のときは前と同じ式を通るので、既存の設計は変わらない。マンデイター II（大型ランチャー 6 基、作例で唯一）を読み込んで、保存形の SHA-256 と、6 基の `launcherGeometry`・`fitSpec`・`missileLauncherSpec` の全数値が変更前と一致（新しく増えた `colSpacing`／`rowSpacing` の項目を除く）。作り直しは不要。
- テスト：`tests/heavy-launcher-spacing.cjs`（3 件）、`tests/ship-launcher-ui.cjs` の 8 件目（編集画面の部品を取り出して動かす。スライダーは大型セルだけ、置くときに間隔が渡る、編集は 1 回の Undo、12.1 m に戻すと保存から消える）。同じファイルの 2〜4 件目は main・基準でも落ちている（取り出した部品にタップ配置の経路が足りない）。

## ブラウザ確認（実際の設計画面と Worker）

スクラッチのスクリプトで、新規配置 → 兵装 → 艦艇用ミサイル発射機 → 大型セル → 4 列・2 段・列 18.5 m・段 14.9 m を入力 → 設置 → 3D 表示をタップ。

- `controls.jpg`：新規配置の発射機の欄。間隔のスライダー 2 本と、本体の寸法（横幅 67.6 m・高さ 27 m）。見出しは「4 列 · 2 段 · 0°」（最初は間隔が 3 番目に来て「18.5 m」と出たので、スライダーを角度の後ろへ移した）。
- `placed.jpg`：置いた発射機。セルの円い蓋が 18.5 m／14.9 m の間隔で並ぶ。状態は「最新確定」、Worker のエラーなし。残る警告は検証用の箱の船体に発電機・機関・艦橋・給電経路が無いことによるもの。
- 左右対称のまま中心線の近くに置いた回では、対の 2 基が重なって「重なって取り付けられない」となり、状態が「計算失敗」になった（配置の拒否による表示。間隔の機能とは別）。
