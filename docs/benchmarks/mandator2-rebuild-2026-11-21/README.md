## 既知の点

- 警告「立体切削 #8303／#8304／#8600 の切り口に薄い壁（0.05〜0.82 m）」が出る。ユーザーのモデルの中の削りで、ビルダーが足したものではない。モデルは変えていない。
- 排熱の不足は、変換装置を「最高速度の 70% の巡航」で決める規則と、反応炉を動かさない決定による（#121 と同じ）。今回は変換装置を機関の列の間に置いたので容積が減り、不足が増えた。
- 性能行の機関ごとの定格推力の合計（5.68e16 N）は艦全体の定格推力（2.03e16 N）より大きい。艦全体の値はノズル側の軸の容量（2.379e26 W）で決まる（上の表）。全力推進のときの入力・効率は主担当の推定で、`solveShipPropulsion` での確認はしていない。
- 機関本体の引き延ばしで、11 基のうち一部は最大の倍率（14 倍）まで届かずに短い長さで止まる。どの部品に当たって止まったかは記録しておらず、**理由は未確認**（設計の結果には浮き・重なり 0 で影響しない）。
- 点防御 63 基（台 4 個が空き）、大型ランチャー 6 基（ラック台が 6 個）は #121 と同じ。
- 画像（`renders/`）：`dorsal`、`ventral`、`port`、`starboard`、`heavy-closeup`、`side-balls-closeup` は `scripts/browser-mandator-layout-saved.cjs --draft --archive data/examples/mandator2/design.json.gz --phase draft-final`（出力先だけ変えた。ゲームの描画コードで保存済みの構造物と兵装を描く。性能計算は含まない）。`editor-exterior`、`editor-xray` は設計画面（実際の Worker）で開いた画面。
- 設計画面（実際の Worker）での確認（2026-11-21、`030055d` のサーバー、ほかのテストと並行）：開くのに 2,075 秒、保存して読み直すのに 2,093 秒。読み直す前後で統計が一致（質量 20.3 億 t、最大加速 1,016 G、出力 7.7e26 W、点検 エラー 0・警告 5）。単独で動かしたときの時間は未測定。
