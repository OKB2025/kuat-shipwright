# 砲身の 3D 形状の変更（2026-11-24）

ユーザー：「点防御の砲身を太くする」「モン・カラマリの球形砲塔の砲身を伸ばす件と、口径 0.45 m 未満のターボレーザーを太くする件も組み込んで」。

- 方式：元の形状データ（data/reference.js）は変えず、読み込み時に砲身部品（barrelCenters の頂点範囲）の頂点だけを動かす（js/core.js reshapeGunBarrels、decodeReference）。砲身以外の頂点は動かさない。部品・棒・板は足していない。
- 太くする範囲：砲身が球・防盾から出た所（exposedStartX）より前だけ。球や防盾の中にある根元は元の太さのまま（原本照合レビュー 2026-11-24 の指摘で変更。以前は根元も同じ割合で太くしていた）。
- 伸ばす範囲：球から出た所のすぐ先の、何も付いていない軸の区間だけが伸びる。その先にある帯・砲口の凹みの底・砲口カラーは形を変えず、伸ばした長さだけ前に平行移動する（同レビューの指摘で変更。以前は全体を一律に引き伸ばしていて、凹みとカラーが 2〜4 倍になっていた）。砲口の凹みの深さ（muzzleRecessM）は原本のまま。
- 点防御 2連装：砲身を中心線から 1.732 倍に（外径 0.231 → 0.40 m）。
- モン・カラマリの球形砲塔：露出砲身（球から出た所から砲口まで）を図面の比（露出砲身 ÷ 球の直径：34TT 1.0、80TT 1.55、200TT 1.75、200TT 3連装 1.45、150TT イオン 1.5）まで +X 方向に伸ばす。34TT 2.79 → 6.0 m、80TT 3.72 → 12.4 m、200TT 4.64 → 17.5 m、200TT 3連装 7.43 → 23.2 m、150TT イオン 5.82 → 16.5 m。球の直径には砲の幅（wm）を使っている（球の直径を頂点から測った照合はしていない）。
- 口径 0.45 m 未満のターボレーザー（口径が無いモデルは外径 × 0.6）を 0.45 m に太くする：200GT 系 ×1.12〜1.26、モン・カラマリ 34TT ×1.75・80TT ×1.31・200TT ×1.05。CR-90・スフィルナの 500MT 系は形を変えず、描かれた口径のままのレーザーに変更（ユーザー 2026-11-24「500MT系は変えずに、『重レーザー』に変更。この口径通りのレーザーにして」）。
- これらは原本（図面・写真測定）の砲身寸法から意図して離れる変更（ユーザー指示による許可済み差異）。差異は砲身だけで、砲塔本体・艦体は変えていない。
- 砲の外形の箱：形を変えた砲は、変形後の頂点を含む箱（drawnExtent）を使う（referenceFitAABB）。干渉判定・艦の外接範囲・機関の再配置はこの箱で決まるので、伸ばした砲身のぶん前に広がる。艦ごとの前後比較は ships.md。
