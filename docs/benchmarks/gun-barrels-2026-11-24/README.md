# 砲身の 3D 形状の変更（2026-11-24）

ユーザー：「点防御の砲身を太くする」「モン・カラマリの球形砲塔の砲身を伸ばす件と、口径 0.45 m 未満のターボレーザーを太くする件も組み込んで」。

- 方式：元の形状データ（data/reference.js）は変えず、読み込み時に砲身部品（barrelCenters の頂点範囲）の頂点だけを動かす（js/core.js reshapeGunBarrels、decodeReference）。砲身以外の頂点は動かさない。
- 点防御 2連装：砲身を中心線から 1.732 倍に（外径 0.231 → 0.40 m）。砲身部品の根元の太い部分も同じ割合。
- モン・カラマリの球形砲塔：露出砲身（球から出た所から砲口まで）を図面の比（露出砲身 ÷ 球の直径：34TT 1.0、80TT 1.55、200TT 1.75、200TT 3連装 1.45、150TT イオン 1.5）まで +X 方向に伸ばす。34TT 2.79 → 6.0 m、80TT 3.72 → 12.4 m、200TT 4.64 → 17.5 m、200TT 3連装 7.43 → 23.2 m、150TT イオン 5.82 → 16.5 m。
- 口径 0.45 m 未満のターボレーザー（口径が無いモデルは外径 × 0.6）を 0.45 m に太くする：200GT 系 ×1.12〜1.26、モン・カラマリ 34TT ×1.75・80TT ×1.31・200TT ×1.05。CR-90・スフィルナの 500MT 系は太くせず、描かれた口径のままのレーザー（重レーザー）に変更（ユーザー 2026-11-24「500MT系は変えずに、『重レーザー』に変更。この口径通りのレーザーにして」）。
- 比較画像：before-after.png（左が main、右が変更後。部品プレビューは形の大きさに合わせて縮尺が変わる）。shots.cjs で撮影。
- 砲の外形の箱（fm）は伸ばした砲身を含めて更新していない（射界・干渉の判定は元の箱）。
- before-after.png の 500MT 系の右側（太くした形）は取り消し前の画像。今は元の形のまま。
