# 砲身の 3D 形状の変更（2026-11-24、2026-11-25 にレビュー後の修正と証拠の取り直し）

ユーザー：「点防御の砲身を太くする」「モン・カラマリの球形砲塔の砲身を伸ばす件と、口径 0.45 m 未満のターボレーザーを太くする件も組み込んで」「この画像をもとに砲身を伸ばして」「3Dモデルの砲身は伸ばす」。

## 何を変えたか

- 方式：元の形状データ（`data/reference.js`）は変えない。読み込み時に、砲身部品（`barrelCenters` の頂点範囲）の頂点だけを動かす（`js/core.js` の `reshapeGunBarrels`、`decodeReference`）。砲身以外の頂点は動かさない。部品・棒・板は足していない。頂点の数も変わらない。
- これは原本（図面・写真測定）の砲身寸法から意図して離れる変更で、ユーザーの指示による許可済みの差異。差異は砲身だけで、砲塔本体・艦体は変えていない。

## 形の決め方（2 回目のレビューの FAIL 3 件への修正を含む）

1. **太くする範囲**：砲身が球・防盾から出た所（`exposedStartX`）より前だけ。球や防盾の中にある根元は元の太さのまま。
2. **点防御のくびれ**（FAIL → 修正）：点防御 2連装は砲身が `exposedStartX` より後ろでも外に出ている。太くし始める位置の手前に、太くした砲身より細い輪が残って「細くなってまた太くなる」形になっていたので、その輪を太くした砲身の太さまで広げる（`neckFill`）。実測：x 1.68 m の輪 0.152 → 0.182 m。もともとそれより太い輪と、内側の砲腔は動かさない。
3. **伸ばす範囲**：球から出た所のすぐ先の、何も付いていない軸の区間だけが伸びる。その先にある帯・砲口の凹みの底・砲口カラーは形を変えず、伸ばした長さだけ前に平行移動する。砲口の凹みの深さは原本のまま。
4. **図面の比の当て方**（FAIL → 修正）：図面の比は「真横から見て球の輪郭より外に見えている砲身 ÷ 球の直径」。モデルの `exposedStartX` は球の輪郭より内側にあるので、そこから測ると見える砲身が 3〜7% 短かった。球の輪郭（中心 + 半径）から砲口までで当てるように直した。
   - 3連装も同じく、真横から見た球の輪郭（x = 8 m）を基準にした。レビュー担当が示した式（砲身の横位置 z での球面 √(R²−z²)）は使っていない。理由：ユーザーの図面は上面図・側面図の輪郭に対する比で測っており（下の「図面」）、外側の砲身ごとに基準を変えると 3 本の砲口が揃わなくなるため。
5. **150TT イオン球の先細り**（FAIL → 修正）：先細りの区間（x 4.357〜9.749 m、半径 0.787 → 0.447 m）は元のまま。伸ばした分は先細りの後ろに入れ、砲口のつば（半径 0.491 m）と凹みは砲口と一緒に前へ移す。先細りの終わり（r 0.447）からつば（r 0.491）までは 11.8 m のごく緩い広がりになる（頂点は足していない）。記録の `taperEndXM` は描いた形と一致するので、`tests/ion-barrel-style.cjs` は main と同じ内容で通る。
6. **砲の外形の箱**：形を変えた砲は、変形後の頂点を含む箱（`drawnExtent`）を使う（`referenceFitAABB`）。干渉判定・艦の外接範囲はこの箱で決まる。

## 図面

- ユーザーの MC80 リバティー上面図（翼あり・なし）と砲の種類の書き込みから、外に出た砲身 ÷ 球の直径を測った。測定の書き込み図：`docs/handoff-2026-11-20/moncal-ball-barrels-measure-2026-11-24.png`（SHA-256 `4a0ea36a65c9cb0a05f6f3b8befe2f413c7869b5f1d1389b3c7d3d36fe0f6775`、方眼は 1 マス ＝ 原図 4 px）。
- ユーザーの原図そのものはリポジトリに入っていない（入っているのは測定の書き込み図だけ）。したがって原図のハッシュは記録できていない。
- 測った比：200TT 3連装 1.45、200TT 単装 1.75、150TT イオン単装 1.5、80TT 単装 1.55、34TT 単装 1.0。
- **許容差**：測定は方眼 1 マス（原図 4 px）刻みなので、比の読み取りの粗さは球の直径に対して ±0.05 程度（こちらの見積もり。図ごとの球の直径の px 数は記録していない）。モデルは測った比にちょうど合わせている（上の実測）。

## 確かめていないもの

- 艦に載せた状態の拡大画像（同じカメラの前後）。
- 球の直径に砲の幅（`wm`）を使っている点：モデルの記録（`sphereRadiusM` × 2）と一致することは上のプロファイルで確かめたが、原図の球との照合はしていない。
