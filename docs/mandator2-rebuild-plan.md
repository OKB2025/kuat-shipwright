## ユーザーの指示

1. **作り直し**：エグゼクターと同じく、エンジンが船体に埋め込まれている。原本に合わせて作り直す。トレンチも作られていないので作る。
2. **斜めの面が階段状になる**：構造物の直線の斜めが階段状になっている（エグゼクターも同じ）。作り直す。
   - 原因：原本から作る構造物を、60 m の高さの帯ごとの水平な板（外形を上から見た多角形を押し出したもの）で積んでいるため、斜めの面が帯の高さごとの段になる。
   - 方針：斜めの面は、帯の板ではなく、上下で外形が変わる部品（`loft` や頂点を持つ `mesh` の構造物）で作る。原本の三角形をそのまま入れない（reference-fidelity-rules.md）。
3. **兵装の配置**（参考画像はマンデイター II の原本）：

| 原本の形 | 置く兵装 |
| --- | --- |
| 小さな張り出し | 点防御 |
| トレンチ内の円形の構造 | 4 連 175 TT ボールターレット・イオン砲 |
| 中くらいの砲塔の台座 | 4 連 175 TT ターボレーザー |
| 大きな砲塔の台座 | 2 連 720 TT |
| 舷側の発射口の並び（2 段 × 6 列の窪み） | 艦艇用の震盪ミサイル発射装置（新しい兵装） |

4. **艦艇用の震盪ミサイル発射装置**（新しい兵装。今回のミサイル系の変更に合わせる）：
   - 原本の発射口の大きさを基準に、他の艦艇にも使える兵装にする。
   - 奥行きはミサイルの長さに合わせ、艦内の区画として表示する。
   - セル数（横の数）と段数で発射口の数が増える。

## 作業の順序（案）

1. 原本の測定：向き・縮尺、船体（楔）と構造物・エンジン・トレンチ・砲座・発射口の位置と大きさ。
2. 構造物の作り方の変更（斜めの面を階段にしない）。まずエグゼクターの構造物で試し、マンデイター II に使う。
3. マンデイター II の船体・構造物・エンジン・トレンチを原本に合わせて作り直す。
4. 兵装：既存の砲種（4 連 175 TT・イオン砲・点防御）の対応を確認し、2 連 720 TT と震盪ミサイル発射装置を追加する。
5. 判定：partConstraints / referenceShape / physicalValidity / evidenceValidity と、作例の性能値の変化。
