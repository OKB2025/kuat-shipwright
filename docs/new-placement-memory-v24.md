# 新規配置の記憶と選択からの配置（v24）

## 直前の配置を開き直す

武装などを配置したあと、もう一度「新規配置」を押すと、以前は構造物の選択に戻っていた。v24 では、外装・内装それぞれで最後に「設置」した部品と設定がそのまま開く（`designNewRemember` と `designNewRestore`）。

覚えるものは次のとおり。

- 分類と部品の種類
- 構造物の形・寸法・すぼまり・向き・装甲板
- 区画の大きさ
- 武装の取付方法・支持台・砲塔の向き

## 選択中の部品をそのまま配置する

部品や武装を選んだまま「新規配置」を押すと、その部品と同じ種類・同じ設定で配置できる（`carryToPlace`）。構造物なら形と寸法が、武装なら取付方法と支持台がそのまま引き継がれる。

- このとき、選んだ構造物は新しい部品の追加元にはしない。
- 船体パーツ（主船体）を選んでいるときは、これまでどおり、その上に置く部品を選ぶ画面になる。
