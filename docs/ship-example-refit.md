# 作例艦の機関・配電・排熱設備

選択可能な艦船27作例を、現在の推進・電力・熱モデルに合わせて組み直す。新しい作例の構築時に改装し、保存済みのプレイヤー設計は保存された装置と配線から計算する。武装の種類と配置は [指定4艦](named-example-armament.md) と [艦種別の系列](example-weapon-families.md) を参照。

## 機関と実際の加速

機関は標準の入力係数 `2e9 W/N` と通常の有限な機関密度を使う。ノズルとは独立した機関本体に必要容積を確保し、旧式機関向けの大きな密度上限や互換冷却を使用しない。機関区画は船体、または元からある機関外装の中に収める。

ISD、ヴェネター、アクラメイター、エグゼクターの目標加速は既存の参照表を使用し、最終的な実質量から必要推力を求める。それ以外は各作例の既存部品の定格推力を引き継ぐため、追加設備の質量も実加速に反映される。戦闘プレビューの機関要求は35%なので、計画最大加速とは別の値になる。

## 反応炉と配電

各作例の既存反応炉を維持し、推進・砲・シールドの同時最大出力に合わせた発電量の増強は行わない。砲撃やシールドへ多く配電すれば、機関が受け取る実電力と推力は低下する。慣性補償、構造維持、反応物供給設備を実区画として搭載し、有限の発電量を現在の計算モデルで使用できるようにする。

各反応炉から実物の配電・蓄電区画を経由し、機関、武装、シールド、冷却設備へ有限容量の配線を接続する。バス給電の機関には古い専用の長い円錐形給電区画を生成せず、短い機関本体を残す。バスの配線を切ると自動給電で代替されず、実際の推力が失われる。

超兵器は元の給電炉を保持し、充電の予約電力も既存の発電量から差し引く。通常の艦載砲と同様に、超兵器の充電熱にも実物の輸送路を設ける。

## 排熱

作例は厳密モードを使用し、通常の内蔵型高エネルギー散逸区画と有限容量の熱輸送路を搭載する。区画の容量と質量は船内に確保した実容積から求める。既存反応炉の発電量と配電条件で実際に動かせる負荷に合わせて容量を決める。冷却設備の消費電力、炉で発生する変換熱、機関・砲・シールドの損失熱、生活・電子設備と冷却設備自身の廃熱を収支へ含める。

船内区画の自動配置では、互いに接する隔壁を容積の重複と誤判定して装置を停止させないよう、パッキング済みの区画同士は実際の直方体群で判定する。実際の容積の重なりは引き続き検出する。

## MC30c

旧小型イオン砲を150 TT球状イオン砲16基へ置き換えた構成は、実際の船内容積を超える反応炉を必要とした。ユーザー指定の500 GT球状単装砲16基、球状3連装PD10基、魚雷・爆弾発射機8基、トラクター2基へ更新する。GR-75のレーザーターレットは2基とし、過大な武装を搭載しない。MC80の添付図に基づく各100基の配置と、指定4艦の武装基数は保持する。

## カタログと計測

艦隊カタログはモデル15で編集可能な作例から生成する。生成時と同じ船体・統計・プロファイルを使って監査し、別の数値表で性能を上書きしない。大艦の生成は独立した断片へ分けられる。

```sh
node scripts/update-ship-examples.cjs --keys imperial,venator --patch /tmp/fleet-main.json --audit /tmp/fleet-main-audit.json
node scripts/update-ship-examples.cjs --merge /tmp/fleet-main.json
```

比較元は [変更前の全27艦の計測](benchmarks/ship-examples-before.json)。計測では、損傷のない冷間状態から30秒間、均衡配電で推進・通常砲・シールドを同時に要求し、実際に割り当てられた電力と推力、発熱を記録する。全要求を同時に満たすことは合格条件にしない。推進のみ、砲撃併用、シールド併用も比較し、有限の電力が各装置で共有されることを確認する。継続排熱の判定は設計プレビューの各運転条件も併用する。
