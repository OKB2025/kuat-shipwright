# 作品資料に基づく亜光速の最高速度

最高速度と最大加速度は別の量として扱う。ISD I/IIの2,300G、アーキテンスの1,800G、CR90の2,100G、スフィルナの2,500G、MC系列の2,100Gはユーザー指定。最高速度を合わせるために機関の推力や密度、発熱、質量を変更しない。

公表された速度はMGLTで保持する。戦闘空間の既存縮尺 `1 MGLT = 20 m/s` はシミュレーションの換算係数であり、スター・ウォーズ世界での物理的定義ではない。大気中のkm/hから宇宙のMGLTを推測して設定値と呼ぶ扱いはやめる。

VウイングとEta2には、旧資料の100/118または120MGLTと、2025年版百科事典の130/128MGLTがある。ここでは新しい明記値を採る。BTL-Bと反乱軍のBTL-A4、各Xウイング型を混同しない。

MC30c、通常型アーキテンス、オナガー、マンデイターII、レキューザント両型、ヘラクロン、旧共和国の小型輸送艦、貨物型LH3210、LAAT/c、降下バージ、C9979については、この調査では宇宙の数値設定を確認できなかった。これらの最高速度は計算上の仮定として区別し、別型や改造個艦の数値を公式値として流用しない。特に、改造Class 546の75MGLTを通常アーキテンスの公表値とは扱わない。値が明記される資料を追加できた場合は表と実装を一緒に更新する。

無推力の機体は公表最高速度を持っていても加速できない。実際の移動では、給電・熱・損傷・搭載質量による推力と加速度の制限を引き続き適用する。
