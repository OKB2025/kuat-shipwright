# 艦隊の射撃と陣形

各艦は、攻撃相手を明示されていなければ、自分の正面にいる敵を優先して射撃します。任務群が移動の基準にする敵と、各艦が撃つ相手を分けて扱います。艦・任務群・合同任務群へ攻撃目標を指定した場合は、その命令を優先します。

移動・定針・待機・護衛の途中でも、探知できる敵が射程と射界に入り、射撃に使えるエネルギーがあれば射撃を続けます。射撃停止命令、遮蔽物、兵装の損傷、蓄電不足などの条件も引き続き反映します。

設計画面の性能諸元には「同時交戦数（対空・迎撃）」を表示します。これは実際の迎撃処理で使う射撃管制枠で、航空機4機の小隊またはミサイル8発の斉射を1枠として扱います。指揮所や追跡用センサーの設計によって変わります。

編成画面と戦闘中の合同任務群への命令で、「合同任務群全体の陣形」を選べます。これは任務群同士の配置を決めるもので、各任務群の内部陣形は維持します。全体の移動速度は参加する任務群に合わせ、後続が遅れた場合も配置を保てるように調整します。

「任務群ごとに独立」で全体陣形を解除できます。個別の任務群へ別の移動命令を与えた場合は、その任務群が全体陣形から離れます。艦への個別命令も、陣形維持より優先します。
