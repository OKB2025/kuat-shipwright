# TIE/in・TIE/saの主翼を一体の太陽光パネルへ置換

[TIE/ln](tie-ln-native-solar-wings.md)と同じく、TIE/inインターセプターとTIE/saボマーの左右の主翼を、それぞれ1個の現行`solarPanel`部品にした。

- TIE/inは「切欠き形」、TIE/saは「折れ曲がり」のプリセットを使う。どちらも以前の作例の実測輪郭（中央部と、内側へ折れた上下の翼板）から作ったプリセットで、折れ線の位置と折れ角もプリセットが持つ。
- 中央部・中央パネル・上下の翼板・外枠・支柱帯・縦梁として別々に置いていた構造物は外した。外枠と桁はパネル自身のディテールになる。
- 厚さはTIE/lnと同じ0.08 m。翼の付け根の面（TIE/inは艦の中心から3.834 m、TIE/saは4.34 m）に置き、左右は鏡写しにする。
- 操縦球やポッドから翼への支持腕と、TIE/inの翼外側ハブは残した。
- 両作例の物理改訂を1にした。古い作例の派生性能データは新しい部品構成から作り直す。保存済みのユーザー図面は変更しない。
