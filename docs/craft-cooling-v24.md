# 小型機の排熱を推進ぎりぎりに（v24）

これまで小型機の作例の排熱装置は、熱の出方が最も大きい運転状態（全力推進・全武装・シールドを同時に使う状態など）の発熱の1.2倍を処理できる大きさにしていた。このため、どの小型機も排熱に余裕があり、熱で推力が制限されることはなかった。v24 では、推力が排熱の上限ぎりぎりになるように排熱を絞った。

## 排熱装置の大きさ

- 排熱装置の大きさを決める運転状態に「推進」（`HEAT_PRESETS.drive`：全力推進とシールド、武装なし）を加えた。小型機の作例の高性能排熱装置は、この状態での発熱の1.05倍だけを処理できる大きさにする（`CRAFT_COOLING_SIZING`、`CRAFT_COOLING_MARGIN`）。
- シールドを張って全力で推進すると、排熱能力の約95%を使う。残りの余裕は武装などの発熱に回る。それを超える発熱は蓄熱器にたまる。蓄熱が上限に近づくと、[熱の自動制御](thermal-governor.md)が推力と発射速度を下げる。
- 機器から排熱装置への熱の経路の容量は、従来どおり各熱源の最大発熱の1.2倍とする。
- 太陽電池翼の排熱能力（`SOLAR.disW`、両面それぞれ）を、1 m² あたり 2.5×10¹⁵ W から 3.9×10¹⁴ W に下げた。TIE/ln では、太陽電池翼の排熱能力が推進時の発熱の約1.06倍になる。

## 加速度の合わせ直し

main の推進モデルでは、機関への入力は接続した反応炉の出力で決まる。排熱装置の消費電力が変わると、機関に回る電力も変わる。そこで各小型機の反応炉の大きさを倍率（`CRAFT_REACTOR_SCALE`）で調整し、戦闘時の推進計算（シールドと排熱装置の消費電力を含む）での定格加速度が、従来の目標加速度（`CRAFT_INTERIOR_TARGETS`）に一致するようにした。倍率は完成した機体で一度だけ測った値である。

| 機体 | 目標加速度 (G) |
| --- | --- |
| ARC-170 | 3,551 |
| Aウイング | 5,100 |
| BTL-B Yウイング | 3,000 |
| ハイエナ級ボマー | 2,250 |
| TIE/in | 4,240 |
| TIE/ln | 4,100 |
| TIE/sa | 2,380 |
| V-19 トレント | 4,696 |
| ヴァルチャー級 | 3,600 |
| Vウイング | 5,200 |
| Xウイング | 3,700 |
| Z-95 | 3,330 |

反応炉の大きさが変わった作例は物理改訂を上げた（TIE/ln は改訂2のまま）。古い作例の派生性能データは新しい部品構成から作り直す。保存済みのユーザー図面は変更しない。

小型機のシールドとハイパードライブの充電は [ハイパードライブの充電と小型機のシールド](hyperdrive-charging.md) を参照。
