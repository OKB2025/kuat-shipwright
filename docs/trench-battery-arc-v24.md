# トレンチ砲群の射界（v24）

トレンチ砲群の旋回角を、壁の向きから左右 ±85°・上下 ±20° に広げた（`TRENCH_BATTERY_ARC`）。以前は、ほかの舷側砲台と同じ ±65° だった。

楔形の船体では、トレンチの壁が艦首側へ少し傾いている。エグゼクター級では約 14° で、壁の向きは艦首から 76° になる。±65° では艦首方向（艦首から 25° 以内）を撃てず、正面の敵に1門も向かなかった。±85° なら、艦首の真正面まで届く。

- 艦隊戦（`surfaceMountArc`）と試験航行の戦闘（`trialLimits`）の両方に適用する。
- トレンチ砲群以外の舷側砲台（ヴェネター級の舷側砲など）は ±65° のままである。
- 射線が船体に当たる向きは、これまでどおり撃てない。
