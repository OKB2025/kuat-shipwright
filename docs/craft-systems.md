# 航空機の機器と費用

添付のUウイング、Xウイング、TIEボマー、TIEファイターの断面図を参考に、独立した機器として不足していた機能を追加しています。機器の配置や用途を図解に寄せ、容量・電力・価格・生還率の数値はゲーム用の仮定としています。

| 機器 | 設計・運用への反映 |
| --- | --- |
| 生命維持 | 有人区画の対応人数、無補給の持続時間、電力・熱 |
| 射出・脱出装置 | 対応人数、撃墜時の乗員生還・損失 |
| 航法コンピュータ | 自立したハイパー航法の準備。アストロメクや指揮機器とも共有 |
| 照準コンピュータ | 武装に対する管制容量。既存の射撃管制区画とも共有 |
| 姿勢制御機器 | 支えられる質量、旋回・空戦時の機動性 |
| レーザーガス供給 | レーザーの連射換算持続時間。補給までの射撃限度 |
| 着陸支持機構 | 着地時に支えられる質量。飛行用のリパルサーとは別の判定 |

「配置」→「操縦・搭乗（小型艇）」で機器を配置し、「性能」で搭載数・容量・持続時間を確認できます。操縦席の編集では座席数と宇宙服による運用を選べます。太陽電池翼、蓄電池、冷却、反応物、配電路、Sフォイル駆動は既存の系統を使い、同じ能力を重複計上しません。

新しい配置見本には対応する機器を配置します。TIEは機内生命維持・シールド・ハイパードライブを追加せず、宇宙服へ依存する構成を維持します。ドロイド機には有人用の生命維持や射出座席を加えません。既存の保存設計の形状を自動変更することはありません。独立した機器を配置した後は、その搭載量に応じた計算になります。

建造費は全設計共通の「機器・兵装の基本費＋体積費・装備費」です。小さい機器でも取り付けや制御系の基本費が必要です。既製機の編集可能な設計図も同じ計算を通し、機体名や既製／自作の区別で価格を変えません。機体1機の建造費に乗員の費用を加えたものが、編成の1機当たりの費用です。

この基準で、既製機と同じ設計のXウイングはいずれも170,178 cr、TIE/lnは87,833 cr、TIEボマーは118,455 crです。機器を取り外したり大きさを変えたりした場合は、その構成に応じて変わります。公式の販売価格をそのまま当てる方式ではありません。

編集できる設計図がない機種は、機体の役割・装備から設備構成を推定して共通単価を適用します。編成の「1機の費用内訳」で設計図による計算か推定かを確認できます。以前の設計機スナップショットも設計図が残っていればバックグラウンドで価格を再計算します。価格更新中は出撃を待ち、古い価格のまま予算判定を通さないようにします。図面を持たない古い性能だけのデータは、保存時の値を維持します。

標準機も設計機も同じ装備容量でガス・生命維持を消耗します。Uウイングなど編集用モデルがない機種の機器容量も、価格に使った設備構成から同じ係数で推定します。

標準機の価格表は `node scripts/update-craft-costs.cjs` で同じ設計計算から生成します。係数や配置見本を変更したときは生成し直し、`node scripts/update-craft-costs.cjs --check` で整合を確認します。
