# 航空機の機器と費用

添付のUウイング、Xウイング、TIEボマー、TIEファイターの断面図を参考に、独立した機器として不足していた機能を追加しています。機器の配置や用途を図解に寄せ、容量・電力・価格・生還率の数値はゲーム用の仮定としています。

| 機器 | 設計・運用への反映 |
| --- | --- |
| 生命維持 | 有人区画の対応人数、無補給の持続時間、電力・熱 |
| 射出・脱出装置 | 対応人数、撃墜時の乗員生還・損失 |
| 航法コンピュータ | 自立したハイパー航法の準備。アストロメクや指揮機器とも共有 |
| 照準コンピュータ | 武装に対する管制容量。既存の射撃管制区画とも共有 |
| 姿勢制御機器 | 支えられる質量、旋回・空戦時の機動性 |
| レーザーガス供給 | レーザーの連射換算持続時間。補給までの射撃限度 |
| 着陸支持機構 | 着地時に支えられる質量。飛行用のリパルサーとは別の判定 |

「配置」→「操縦・搭乗（小型艇）」で機器を配置し、「性能」で搭載数・容量・持続時間を確認できます。操縦席の編集では座席数と宇宙服による運用を選べます。太陽電池翼、蓄電池、冷却、反応物、配電路、Sフォイル駆動は既存の系統を使い、同じ能力を重複計上しません。

新しい配置見本には対応する機器を配置します。TIEは機内生命維持・シールド・ハイパードライブを追加せず、宇宙服へ依存する構成を維持します。ドロイド機には有人用の生命維持や射出座席を加えません。生命維持などの機器は古い保存設計へ自動追加せず、独立した機器を配置した後は、その搭載量に応じた計算になります。

建造費は全設計共通の「機器・兵装の基本費＋体積費・装備費」です。小さい機器でも取り付けや制御系の基本費が必要です。既製機の編集可能な設計図も同じ計算を通し、機体名や既製／自作の区別で価格を変えません。機体1機の建造費に乗員の費用を加えたものが、編成の1機当たりの費用です。

主翼・太陽光パネルを含む現在の基準では、既製機と同じ設計のXウイングはいずれも178,920 cr、TIE/lnは95,225 cr、TIEボマーは133,279 crです。機器を取り外したり大きさを変えたりした場合は、その構成に応じて変わります。公式の販売価格をそのまま当てる方式ではありません。

編集できる設計図がない機種は、機体の役割・装備から設備構成を推定して共通単価を適用します。編成の「1機の費用内訳」で設計図による計算か推定かを確認できます。以前の設計機スナップショットも設計図が残っていればバックグラウンドで価格を再計算します。価格更新中は出撃を待ち、古い価格のまま予算判定を通さないようにします。図面を持たない古い性能だけのデータは、保存時の値を維持します。

標準機も設計機も同じ装備容量でガス・生命維持を消耗します。Uウイングなど編集用モデルがない機種の機器容量も、価格に使った設備構成から同じ係数で推定します。

「配置」→「動力・推進」に、独立した「主翼」と「太陽光パネル」があります。保存データでもそれぞれ `wing`、`solarPanel` の専用部品です。

- 主翼は側面から見る翼弦方向の断面を、薄い6頂点の翼型で表します。前縁から22%の位置が最も厚く、後縁へ長く細く絞る形です。未回転時は艦首側（ローカル+X）が前縁です。上から見る平面形状は翼弦・翼幅・輪郭頂点で別に編集でき、直線翼・テーパー翼・後退翼を出発点にできます。面積と露出に応じて散熱し、高エネルギー用と低温用を選べます。Sフォイルの回転起点や駆動は、この主翼に設定します。自由編集用メッシュへ変換済みの形状は維持します。
- 太陽光パネルは六角形の集電面と、その縁・対角線に沿う骨組みを持ちます。TIE/ln風の六角形、TIE/in風の切り欠き、TIE/sa風の折れ形状を選び、輪郭や骨組み幅、折れ角、中央の平面部分の幅を編集できます。集電面の面積に応じて発電し、両面で散熱します。骨組みを別の発電面や冷却装置として数えません。

両パーツとも頂点編集用のメッシュへ変換して自由に変形できます。折れた太陽光パネルの変換では集電面の情報を保ち、側面の厚さを発電面積に加えません。移動・左右対称・Undo・保存後の再読込にも対応します。Sフォイルは収納すると散熱面が隠れて最大能力が下がり、被弾してパーツが失われると対応する散熱・発電能力も失われます。

ARC-170、BTL-B、ハイエナ、V-19、ヴァルチャー、Vウイング、Xウイング、Z-95の主翼33枚と、TIE系の太陽光パネル14枚は専用パーツです。実測した輪郭・寸法・搭載物・Sフォイルの設定を引き継ぎます。Aウイングは胴体と一体の機体形状を維持し、小さな安定翼は構造材のままです。以前の「構造材＋翼機能」の保存データも、読み込み時に専用パーツへ移行します。さらに古い「外装型高エネルギー散逸装置」は翼内なら主翼へ統合し、単独なら寸法・ID・熱輸送路を保って主翼へ移行します。

寸法と座標は小数で入力でき、寸法スライダーは0.01 m刻みです。構造物・立体切削・区画の各辺は0.02 mから編集できます。操縦席などの機器の最小径は機器ごとの制限を使い、規格機関の寸法制限は維持します。数値欄では0.064 mなどのより細かな値も入力でき、保存時に整数へ丸めません。

標準機の価格・冷却性能の表は `node scripts/update-craft-costs.cjs` で同じ設計計算から生成します。係数や配置見本を変更したときは生成し直し、`node scripts/update-craft-costs.cjs --check` で整合を確認します。
