# 対艦砲の命中率と実弾散布

艦隊戦・RTSの期待命中率と、3D操艦で発射する対艦砲の実弾に、同じ2軸の正規分布による角度散布を使う。射界、砲塔の可動範囲、実際の砲口、発射エネルギー、イオン効果は変更しない。PDの追尾と、プレイヤーが機首を向ける戦闘機の固定レーザーは、従来の迎撃・操縦用散布を保つ。

基準は全長1,600 m・幅868.4 m・高さ444.017 mのISDを真横から狙う場合。ISD作例の照準品質0.7041667と、正常に稼働する射撃管制があれば、その砲の通常最大射程で約50%命中する。長射程砲は40 km、中射程砲は22 km、近距離砲は9 kmが通常最大射程。砲の種類に応じた最大射程を越える射撃は命中率0で、既存の射界判定でも射撃対象から外す。

| 長射程砲で同じISDを狙う条件 | 命中率 |
| --- | ---: |
| 40 km・正常な射撃管制 | 50.0% |
| 20 km・正常な射撃管制 | 85.3% |
| 40 km・射撃管制なし、または完全停止 | 14.8% |

目標が大きいほど、近いほど命中しやすい。艦首を向けた目標は見える幅が狭くなる。センサー・艦橋から求める照準品質の低下、射撃管制の損傷や給電停止は散布を広げる。戦闘機の実物の照準コンピューターも射撃管制として認識し、既に照準品質に含まれる`fireK`を二重に加算しない。RTSの追跡精度、乗員不足、部位狙撃の追加補正も引き続き適用する。

標的の当たり判定は既存の3D操艦と同じ、全長・幅・高さに合わせた回転楕円体を使う。上記の高さには艦橋も含まれるため、描画用の船体三角形そのものに対する命中率ではない。艦隊戦の期待値はこの楕円体の投影楕円を積分する。3D実弾は実際に散布した方向へ進み、既存の線分と楕円体の交差で命中する。艦隊戦の描画用弾も交差したときだけ着弾効果を出し、外れた弾を自動で命中させない。

シード固定の20,000発で実際の3次元楕円体との交差を数えると、最大射程で50.235%となる。期待値50%との差は標本誤差内。各砲身は独立に散布し、複数砲身が同じ誤差方向を使い回さない。
