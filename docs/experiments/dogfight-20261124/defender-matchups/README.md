最初の喪失刻みでD側の損失が少ない／多い／同数は 40／0／0 戦。

Xの初期シールド容量はDの約2.82倍。shield 条件は容量を合わせ、充電・予備バンク・機体形状等は維持。profileは生成した戦闘プロフィールの計算値で、被弾後の値は含まない。Aは24発、XとDは12発、inとlnは6発／機。

同じシードでも条件を変更するとシミュレーション内の乱数列の消費が分岐する。各変更の勝数差は加算できない。単一の初期編隊、単一の近傍目標選択を使うドッグファイト・シミュレーターでの結果。

全条件の側別勝数・喪失数・時間・未決数は summary.csv、試行別は runs.csv、標準12対12の開幕は opening.jsonl。再実行は reproduce.py 冒頭の使い方を参照。

## 判断

対Xの12対12では、X側だけの僚機判断を無効にするとDが7勝から31勝に増え、D側だけを無効にしても7勝だった。特にX側の対向時の横移動だけを外すと24勝になった。標準条件ではTIE/D側が全40戦の最初の撃墜刻みで先行したが、累計喪失は20秒から30秒の間に逆転した。各撃墜の機動や武器への帰属は調べていない。

Aウイング戦の勝敗は両軍のミサイル使用の有無で逆転する。A側のみ搭載上限を24発から12発にしても全40戦で記録された試行結果が一致した。片側だけミサイルを外す比較は未実施。TIE/in・TIE/ln戦では12対12でもDが計79勝1敗だった。全840件は新規680件と過去の160件からなり、時系列の確認に既存の40件をもう一度走らせた。
