損失は被撃墜機別の直接原因。味方に命中した弾もあり、敵への撃墜クレジットとは異なる。A対lnでTIE側2機の砲と直接損傷の混合を単独原因に割り当てていない。
 
生成器体積Vの補正は min(1,(V/61561.1)^0.8231732453)。試験用に shieldBuffer だけに新旧補正の比を適用し、再充填出力、予備容量は元の値とした。新容量はX 2149.81、A 248.28、D 2437.86、アヴェンジャー1351.23 kt。ln・inは0。X対inの直接砲損失は69機（元の141機）。7.5倍を直接掛けた場合との微小な丸め差で40戦中5戦の終了時刻または損失が変わった。これら5戦は直接乗算で従来の記録を再現した。
