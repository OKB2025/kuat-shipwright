# Xウイングのシールド容量試験
ゲーム版790afd4。TIE/in対Xウイングの4対4を8 km対向、惑星あり、制空任務、シード21～40の両開始側で各倍率40戦。選定値は **7.5倍**。Xウイングだけのプロファイルを複製し、shieldBufferだけを乗算。初期容量は286.64 ktから2149.81 kt。充填出力・予備容量・熱・TIEの値に別途倍率を掛けていない。基準は前回の記録を使用。

7.5倍でXは81機、TIE/inは119機を喪失。300秒到達19戦（X判定勝ち1、TIE判定勝ち2、同数16）。砲で最初の区画が失われた機数を計数した。この40戦で選んだ倍率で、別シードや別機種との対戦は未検証。
