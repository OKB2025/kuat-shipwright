# TIEのパネル脱落とミサイルなしの4対4

8bf82e1 に tie-section-loss/tie-sections.patch、続いて panels.patch を適用。従来の速度AI、4対4、8 km対向、両側各20戦、seed 21–40。ミサイルありは各機6発、なしは搭載も0。区画の直撃破壊は両条件共通。判定は撃墜数で、全戦300秒以内に決着。

|搭載|in勝|ln勝|相討ち|損失in/ln|決着秒中央値|ミサイル発射数|
|---|---:|---:|---:|---:|---:|---:|
|missile|18|22|0|129/123|26.625|155|
|guns|16|24|0|133/125|27.25|0|

発電・排熱は既存のパネル単位の稼働率を使用。TIE/inの翼端砲と翼側姿勢制御器は作例の部品配置に基づいて所属を指定。姿勢制御器の喪失による旋回補正は健全な制御器の容積割合の平方根。TIE/lnの砲と姿勢制御器は胴体に残る。修理・再出撃およびブラウザ表示は試験対象外。

再現は前回の speed-ai-missiles/missile-trials.patch と同じ試験スクリプトに empty-load.patch を適用し、EMPTY=1 で搭載なし。check.cjs は KS_TEST_ROOT に試験版を指定して node で実行。
