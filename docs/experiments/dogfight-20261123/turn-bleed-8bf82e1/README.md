# 旋回時の速度損失を下げたリモデル機の4対4

試験対象は `8bf82e1`、係数変更は `d37e305`。対照は同じソースで航空機の `TURN_BLEED.craft` だけを 0.40 に戻したもの。1 rad 旋回する間の減速項による速度倍率は exp(−0.5 × 係数 × 角度) で 0.819 → 0.882。推進、抵抗、高度交換は別に作用する。艦の係数は 0.40。
