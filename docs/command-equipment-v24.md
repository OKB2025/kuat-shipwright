# 艦橋・センサー・通信装置の統合（v24）

インペリアル級の艦橋本体・センサー・通信装置は、形状の異なる2組（`isd_*` と、ハンマーヘッド型 ISD-I モデルの `isdh_*`）が部品一覧に並んでいた。ユーザーの指定で1組に統合し、名前を改めた。

| 部品 | 形状 | 以前の名前 |
| --- | --- | --- |
| 大型統合艦橋 | `isd_bridge` | インペリアル級 艦橋本体、インペリアルI級 艦橋本体（ハンマーヘッド） |
| ISD-72x複合センサドーム | `isd_sensor_port` / `isd_sensor_stbd` | ISD 球形センサー、インペリアルI級 標的追跡ドーム |
| 外装式指向性通信装置 | `isd_mast` | ISD 通信マスト、インペリアルI級 通信アンテナ |

ヴェネター級の2つの艦橋本体も改名した。

| 部品 | 形状 | 以前の名前 |
| --- | --- | --- |
| 分散式艦橋航行 | `ven_bridge_stbd` | ヴェネター 航行艦橋本体 |
| 分散式艦橋航空 | `ven_bridge_port` | ヴェネター 航空指揮艦橋本体 |

- ハンマーヘッド型の4部品（`isdh_bridge`、`isdh_sensor_port`、`isdh_sensor_stbd`、`isdh_mast`）は、どの作例にも使われていなかった。部品一覧と形状の一覧（`REFERENCE_ASSETS`）から外した。
- 保存済みの設計にあるハンマーヘッド型の部品は、読み込むと同じ位置の大型統合艦橋・ISD-72x複合センサドーム・外装式指向性通信装置になる。エグゼクター級専用艦橋と同じ移行処理である（[エグゼクター級の組み直し](executor-stl-rebuild.md)）。
- 部品の名前が以前の標準名のままなら、読み込み時に新しい名前へ置き換える。ユーザーが付けた名前は変えない。
- 形状データそのものは `data/reference.js` に残す。過去の公開記録が、このファイルの SHA-256 で検証されるためである。
