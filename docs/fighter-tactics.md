# 航空隊の戦闘と母艦への追従

飛行隊を「自動」にすると、戦闘機は敵の攻撃隊を迎撃し、味方攻撃隊の進路を守り、敵機を掃討して制空します。敵航空隊がいなければ艦艇への攻撃に加わります。これはプレイヤー側とAI側の各勢力で共通し、飛行隊へ個別に指定した攻撃・制空・直掩・待機命令を優先します。

迎撃では敵部隊の進行方向も見て接触地点へ向かいます。攻撃隊の護衛機は母艦上空に留まらず、攻撃隊とともに前進します。対艦攻撃ではこれまでの攻撃航過と離脱を維持し、固定砲は砲身の向きにだけ射撃します。戦闘機は射撃のために艦尾へ停止し続けず、攻撃後や消耗時は母艦へ帰投します。

自動任務の内容は戦術図の飛行隊一覧に表示します。手動で「制空」を指定するとその地点を中心に敵機を追い、「直掩」では指定した艦の周囲を守ります。「待機・帰還」で出撃を止めて呼び戻せます。

母艦がハイパースペースへ離脱する際は、まず飛行中の機体を呼び戻します。間に合わなかった機体でも、実際に使用可能なハイパードライブを搭載していれば、自機のドライブで母艦の行き先へ追従します。標準機だけでなく、自作機の搭載ドライブも反映します。同じ飛行隊に非搭載機が混ざっていても、搭載機の離脱を妨げません。非搭載機は母艦の離脱までに着艦する必要があります。

自力離脱にはジャンプ準備と航路に沿った移動時間がかかり、中隊ごとのドライブ性能で到着時刻が変わります。先着した機体は母艦を待ち、母艦がさらに移動した場合は追い直します。再合流後は通常の着艦口から帰艦します。発着艦途中の中隊は、すでに艦内にいる機体と外にいる機体を区別して扱います。

作戦図では自力離脱中の機体と航路を水色で示し、「母艦を追う航空機」の欄に機数・行き先・到着待ちを表示します。星系間航空攻撃の任務と、自動で母艦を追う離脱処理はそれぞれ独立しています。
