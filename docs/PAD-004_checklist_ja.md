# PAD-004 実機検証チェックリスト — ALLONE ALG-MOGPADSCN

対象：KUAT SHIPWRIGHT のゲームパッド入力（指示書 v13 第12章・15.5）。
この表はユーザーが実機で記入する。**OSペアリング／ブラウザ認識／ゲーム内操作は別項目**として記録し、ある環境の結果を別の環境の保証にしない。

## 0. 機種について（2026-10 時点で確認できた範囲）

- ALG-MOGPADSCN は ALLONE「スマホ用モバイルゲームパッド」のシナモロール版。販売ページ（ビックカメラ）の記載：Bluetooth 接続、iOS 16 以上／Android 13 以上のスマートフォン対応、スマホ幅 102〜177 mm・厚さ 12 mm 以下。
- 同シリーズの黒（ALG-MOGPADB）の記事には USB と Bluetooth の両方の記載がある。SCN 版の USB 接続、**PC（Windows/macOS）対応はメーカー記載なし＝未確認**。
- 動作モード切替（Android／iOS／PC など）があるかは未確認。取扱説明書にあれば、試したモードを記録すること。
- 上記以外の挙動は保証しない。結果は下の表に書く。

## 1. 準備

1. ゲームを開く（https のページであること。http ではブラウザがゲームパッドを無効にする）。
2. タイトル画面下の「ゲームパッド」ボタン（設計画面では「設計図」→「ゲームパッドの診断と設定」、どこでも Back＋Start）で**診断画面**を開く。
3. 診断画面上部の表示を確認する。
   - 「このブラウザは Gamepad API に対応していません」→ ブラウザ非対応（接続の問題ではない）
   - 「安全な接続（https）ではないため…」→ ページの開き方の問題
   - 「ゲームパッドが検出されていません…」→ API はあるがパッド未認識。いずれかのボタンを押す（ブラウザはボタンを押すまで通知しない）
   - 「ゲームパッドを認識しています」→ 認識済み
