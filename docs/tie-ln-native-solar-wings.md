# TIE/lnの主翼を現行の太陽光パネルへ置換

以下の数値・検証はPR #75時点の記録。後続の[加速・抵抗校正](calibrated-propulsion-and-power-loss.md)では、ユーザー指示に従いTIE/lnの実リアクターを小さくしている。主翼の左右各1部品という構成は継承する。

TIE/ln作例の左右の主翼を、それぞれ1個の現行`solarPanel`部品にする。六角形プリセットが持つ形状と一体のディテールを使い、外枠・中央ハブ・桁・支柱・フランジを別の構造物として追加しない。操縦球から翼への接続柱2本は保持する。

旧作例のパネル本体も、生成時には既に`solarPanel`へ変換されていた。今回取り除くのは周囲の34個の構造物で、パネルも現在の標準仕様へ置き換える。元の7.24×8.346mの輪郭、左右の位置・姿勢を継承し、現行UI標準の厚さ0.08mと六角形プリセットを使う。枠や桁を個別に選択・配置する必要はなくなる。

|項目|変更前main|置換後|
|---|---:|---:|
|設置部品数|59|25|
|質量|10.330584t|8.406519t|
|太陽光パネル数|2|2|
|集電面積の合計|100.953216m²|100.953216m²|
|太陽光発電出力|6.05719296×10¹⁶W|6.05719296×10¹⁶W|
|骨組み質量|0.178078t|0.178078t|

質量は約1.924t、18.6%減る。共通Coreが実際の部品・形状・装甲から再計算した値で、TIE専用の質量補正や密度変更は加えていない。各パネルの発電・放熱機能、左右の対称参照と保存可能な形状設定を保持する。

新規のTIE/ln作例へ適用し、既存のユーザー図面にある枠や設備を自動削除しない。古いTIE/lnの派生性能データは、新しい作例の部品構成から再生成する。

加速・抵抗の全エンジン共通校正は、主翼を先に交換するというユーザー指示に従い、この変更へ含めていない。新しい実質量を確認したうえで校正を続ける。

検証のコマンド・結果と実ブラウザ画像は以下へ保存する。Chromiumによる確認で、実Safariは未検証。

- [部品・質量・発電と関連回帰試験](benchmarks/tie-ln-native-solar-validation.json)
- [実Worker・WebGL・左右主翼の選択と編集](benchmarks/tie-ln-native-solar-browser.json)

専用7件はすべて成功。関連18ファイル144件は133件成功・11件失敗で、11件すべてを変更前mainでも再現した。[既存失敗の比較記録](benchmarks/tie-ln-native-solar-known-failures-baseline.json)に同じ試験名・ソースハッシュ・終了コード1を残し、全試験成功とは扱っていない。実ブラウザでは両翼の選択・編集、発電・放熱・質量の表示、保存データ保持を確認し、ページ・コンソール・WebGLのエラーは0だった。
