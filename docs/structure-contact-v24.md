# 構造物どうしの接触判定（v24）

ミュニフィセント級の艦橋塔は、STL から測った薄い層を積み重ねて作っていた。層と層の間には数 m のすき間があり、塔全体が浮いていた。それでも点検ではエラーにならなかった。構造物どうしの接触を、外接する箱（バウンディングボックス）が重なるかどうかだけで判定していたためである。

## 判定の変更

二つの構造物は、形どうしが接しているときだけ接触とみなす（`groundingStats`）。

- 片方の表面から取った点が、もう片方の形の中、または形から許容距離（全長の 0.1%、1.5〜6 m）以内にあれば接している。
- 箱が重なっていても、形が離れていれば接していない。
- 区画や装備との接触は、これまでどおり箱で判定する。

## 作例艦の修正

新しい判定で浮いていると分かった構造物には、作例を組み立てる最後に接続支柱を足した（`bridgeLooseStructures`）。

- 支柱は、その構造物の下面から、真下にある接地した構造物または船体まで立てる。
- 船体の下に吊り下がる構造物は、上面から真上へ立てる。
- 装備が載っている構造物は動かさない。

| 作例艦 | 浮いていた構造物 | 足した支柱 |
| --- | --- | --- |
| エグゼクター級 | 都市・腹部のテラス 31 | 26 |
| ミュニフィセント級 | 艦橋塔の層 7 ほか | 4 |
| ルクレハルク級・LH-3210 | 艦尾の塔 1 ほか | 3 |
| MC80 ホーム・ワン | 後部背面センサードーム | 1 |
| レキューザント級（弩級） | 後部舷側の構造物 2 | 2 |

## 2026-11-10 の見直し

ユーザー提供の原本との照合で、上の支柱の多くは原本にない追加物で、浮いた原因は変換の側にあった。原因を直した作例では支柱が付かない。

| 作例艦 | 原因 | 支柱（前 → 後） |
| --- | --- | --- |
| ミュニフィセント級 | 測定行の間引きで構造物の端の断面が失われていた（`fairRows`） | 4 → 0 |
| エグゼクター級 | 平面の楔形の船体が原本からはみ出し、以前の船体に対して測った段丘が浮いていた。船体を当てはめ直し構造物を作り直した（`docs/executor-stl-rebuild.md`） | 26 → 4（原本でも浮いている板） |
| ルクレハルク級・LH-3210、レキューザント級・弩級、ネビュロン B、MC80 ホーム・ワン | 未調査 | 変わらず |

生成済みの作例（2026-11-10 時点）では、上の表の数はネビュロン B 2、レキューザント級 2 も含む。
