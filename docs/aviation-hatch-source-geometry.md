# 航空ハッチの生成元

航空ハッチの候補面・開口範囲は、航空区画の切り取り前の編集元形状から求める。切り取りや機器の配置でできた `_clip` / `_packing` は候補生成の入力にしない。候補面の判定と、開口表面の描画位置を求める処理で同じ元形状ビューを使う。

このビューは元の部品を変更せず、派生形状の参照だけを除いたコピー。実際の区画の表示、選択、衝突、格納容量、質量は従来どおり切り取り済みの有効形状を使う。ハッチを追加・変更・削除しても区画を切り取り前の大きさへ戻さない。元形状と配置情報は既存の保存・復元経路で保持する。

開口先は実際の外皮へのレイキャストで求める。別の構造物や離れた天井を無条件に開口する変更は含まない。ハッチの面ID、開閉状態、既存の安定IDも引き続き保持する。

`tests/aviation-hatch-preclip-source.cjs` は、曲面の船体内で切り取られた区画から消えていた艦首側候補、明示的な切り取り配置と旧図面の自動切り取り、ハッチの生成・開閉・方式変更・削除、保存・再読込、実描画形状と格納容量の保持、離れた外皮への誤接続を確認する。

関連する既存試験は `clipped-hangar-hatch.cjs`、`hangar-hatch-editing-ui.cjs`、`aviation-aperture-renderer.cjs`、`closed-hatch-armor-area.cjs`、`venator-hatch-context-ui.cjs`。NodeのCore・描画・編集契約の試験であり、実Safariでの操作確認を示すものではない。最終統合後の実行結果はPRの検証記録を参照。
