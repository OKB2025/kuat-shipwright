# ハイパードライブの充電と小型機のシールド

## ハイパードライブは余剰電力で充電する

これまでは、ジャンプの瞬間に反応炉の出力がハイパードライブの消費電力（`有効容量 × K.hyperW`）と艦内負荷の合計を上回っていなければ、ジャンプできなかった。v24 からは、ドライブを余剰電力で充電する。

- 満充電の量は、ドライブの定格消費電力の10秒分（`HYPER_CHARGE.seconds`）とする。
- 充電に回るのは、その時点の負荷（推進・シールド・武装・艦内負荷・冷却）に使われずに残った電力だけである。充電の速さはドライブの定格消費電力を超えない。余剰が少ないと、充電に時間がかかるだけでジャンプはできる。
- 充電は常に行う。航行中に余剰電力があれば、ジャンプの指示を出す前から満充電にしておける。
- ジャンプの指示を出すと、従来どおり起動の段階（1.8秒）に入る。満充電でなければ、満充電になるまで起動の段階で待つ。表示は「ハイパードライブ充電 ○% · 行き先へ あと約○秒」になる。余剰電力がなければ「余剰電力なし — スロットルを絞ると充電できます」と表示する。
- 充電を待つ間は、スロットルを自動で全開にしない（main では起動と同時に全開にする）。小型機はエンジンを絞って慣性で進めば、推進に使っていた電力がそのまま充電に回る。満充電になると、main の仕様どおりスロットルを全開にし、突入に必要な巡航速度まで加速してから突入する。
- ジャンプすると充電を使い切る。
- 設計画面の諸元では、「跳躍電力 可／不足」の代わりに、停止した状態での余剰電力（反応炉出力 − 艦内負荷 − レイ・シールド、大型艦はさらにシールドの3割を保つ）で満充電までにかかる秒数を表示する。余剰がなければ「充電用の余剰電力なし」になる。
- 艦隊用のプロファイルに定格消費電力（`grid.Dj`）を加えた。v24 より前のプロファイルには値がないため、その艦のドライブは常に満充電として扱う。

艦隊戦の部隊も同じ規則で充電量を記録する（`fleetPowerStep`）。ただし、艦隊戦の撤退・到着の時刻はこれまでどおりで、充電量では待たない。

## 小型機のシールドは「気休め程度」

作中ではシールドを持たないTIEがXウィングと渡り合っている。小型機のシールドは、機体の生存性を大きく左右するものではない。そのため、小型機の作例のシールドの目標強度は、推進の基本負荷（35%）・艦内負荷・レイ・シールドを差し引いた残りの電力の98%に収まるまで下げる（下限0.1%、これまでの下限は10%）。Xウィングは約0.9%、Aウィングは約2.4%になり、反応炉の出力でシールドを含む基本負荷をまかなえる。

- 保存済みの設計を読み込むときの目標強度の下限も、10%から0.1%に下げた。設計画面のスライダーも1%から選べる。
