# 質量に比例する減速と実出力スロットル

この記録はPR #73時点の規則と検証を示す。現在の抵抗校正と最高速度は[推力と抵抗が釣り合う最高速度](force-balanced-sublight-speed.md)を参照。以下の全艦共通の60秒係数と固定速度上限は、その後の基準速度への校正に置き換わる。

推進へ給電しないまま大型艦が最高速度を保ち、全電力を兵装へ回せる動作を変更した。スロットルは速度の目標ではなく機関の出力要求を表す。実際の推力、噴射、音、出力計は、その要求に対して機関が受け取れた電力から求める。

## 運動の規則

艦の実質量を `M` kg、速度を `v` m/s、実給電後の推進加速度を `a` m/s² として、共通Coreで次を積分する。

```
dv/dt = a - k v
k = M × ln(2) / (1e11 × 60) [1/s]
```

これはゲーム上の抵抗の規則である。1億tの艦は無推力時に60秒で速度が半分になる。減速の係数は実質量に正比例し、艦種・全長・クラスの境界では切り替えない。10tの小型機が60秒後に失う速度は約0.00000693%、100万tでは約0.691%、1,000万tでは約6.70%となる。

質量は既存の推進プロファイルのkg、熱プロファイルのkg、集計質量tからの換算の順で参照する。質量のない旧情報から外形を使って重さを捏造しない。速度と変位は同じ指数関数の解析解から求め、小型機の微小な抵抗にも桁落ち対策を入れている。

速度維持にも抵抗を補う実推進電力が必要になる。兵装優先で推進の実給電が0になった場合や、熱停止・機関損傷時には、現在速度から質量に応じて減速する。停止へ瞬間移動させない。既存のゲーム速度上限は有償の加速に適用し、既に上限を超えた速度を切り捨てない。上限到達中も要求した機関の電力・発熱を計上する。

公試、直接操縦、艦隊戦、平時の艦隊移動、随伴艦、艦載機、無給電・行動不能・落下経路で共通処理を使う。操縦終了後など、移動命令のない平時の艦も移動時計を再開する。落下時の重力は従来の値を保ち、同一更新で二重に移動させない。

## 操縦と表示

出力段階は後進25%、0%、25%、50%、75%、100%。同じ出力指令なら現在速度にかかわらず同じ定格割合を要求する。給電・伝達・損傷・熱・構造・慣性の既存制約を通した実出力を使用するため、指令100%でも受電や有効推力は100%とは限らない。

操舵も実推進電力を使う。スロットル0%で操舵した場合、操舵への給電を主機の前進力や主噴射へ流用しない。主噴射の発光とプルームは実主推進出力に追従し、出力0では消える。ノズルの形状やポリゴン数は増やしていない。

熱停止と推進出力不足を操縦画面に表示する。高度下限で実速度を補正した後に速度表示を更新する。設計の定格値や保存プロファイルの形式は変更していない。

## アップロード艦の熱停止の原因

共通の発熱分配に、明示的な熱源割合 `0` を既定値 `1` と解釈する箇所があった。実出力のないシールド熱源へ発熱を配分し、その小さな経路が過熱して全艦停止する。2箇所の既定値処理を `||` から `??` へ変え、0を保持した。未指定時の既定値と発熱総量は保持する。

提供された同一図面・物理プロファイルを、変更前main `48cfbede2a5b333961601c57a18549ccf77fee8b` の操縦・配電・熱処理で比較した。冷間開始、通常配分、満充電、射撃なし、定格推進要求、刻み0.05秒の管理された再現では、変更前は16.05秒で熱停止し、この2箇所だけを修正すると240秒間オンラインで、最大蓄熱率は約67.15%だった。これはユーザーの実プレイ時間の測定ではない。今回の新しい運動規則とは独立に原因を切り分けた。

元の私有図面と生成プロファイルは公開しない。[集計した再現記録](benchmarks/zero-share-thermal-reproduction.json)に条件・ソースハッシュ・結果を残した。骨組み重量・縦強度、機器定格、熱容量・排熱量・熱停止閾値の係数は調整していない。
