# シールドの偏向と吸収（v24）

シールドは、受けた攻撃を全部止めるか全部通すかの二択ではない。遮蔽する力を持ち、その力が 100% から下がるほど、ターボレーザーの火力が少しずつ船体に届く。テラトン級のターボレーザーを受けながら艦がすぐには壊れないこと、そしてシールドを失った艦が被弾ですぐ壊れることを、この仕組みで説明する。

## 二つの働き

シールドの強さ f は、いまのシールドのエネルギーを容量で割った値（0〜1）である。ビーム（ターボレーザーなど）の命中ごとに、次の順で処理する。

1. **逸らす。** 命中の `deflectMax × f`（`deflectMax` = 0.82）を逸らす。逸らした分はシールドのエネルギーを使わず、艦の外へ出る。
2. **吸収する。** 逸らしきれなかった分のうち `1 − (1 − f)^leakK`（`leakK` = 2）を吸収する。吸収した分だけシールドのエネルギーを使う。吸収した分は艦内の熱にならない（2026-11-16 のユーザー決定「シールドの吸収熱は無くして、単にシールドを生成する時に作動熱のみで」。以前は 6% が熱になっていた）。シールドの熱は、シールドを張っている間の作動熱（`HEAT.waste.shield` × 負荷）だけ。吸収した分の 88% は艦外へ出て、12% は一時的にため込まれる（ため込んだ分も艦外へ出す）。ためられる量に上限があり、上限を超えた分は吸収できない。
3. **突き刺さる。** 残りが船体に届く。シールドのエネルギーやため込める量が足りないときも、その不足分が船体に届く。

| シールドの強さ | 逸らす | 吸収（消費） | 船体へ |
| --- | --- | --- | --- |
| 100% | 82% | 18% | 0% |
| 90% | 73.8% | 25.9% | 0.3% |
| 70% | 57.4% | 38.8% | 3.8% |
| 50% | 41% | 44.3% | 14.8% |
| 30% | 24.6% | 38.5% | 37% |
| 10% | 8.2% | 17.4% | 74.4% |
| 0% | 0% | 0% | 100% |

**2026-11-20 追記（`SHIELD_MODEL.debit`）**：ユーザー指示「シールドの削り値を減らして」「砲火がシールドを減らす量そのもの」「航空機による対艦攻撃ができるくらいまで引き伸ばす形に」により、吸収した分のうちシールドのエネルギーから引くのは `debit` 倍（現在 0.25。数値は実装側の選定）になった。上の「吸収した分だけシールドのエネルギーを使う」は `debit` = 1 のときの説明である。吸収量そのものの上限は `min(吸収すべき量, シールド残量 ÷ debit, 一時保持の空き ÷ beamStore)` で、`debit` = 0.25 では満タン時に一時保持の上限（容量の約 2.9 倍）が強さの上限（4 倍）より先に効く。一時保持が埋まると、シールドが残っていても超過分は船体に届く（この頻度と量は未計測。物理レビュー 2026-11-20 の指摘）。イオンのシールド消費（0.05）には `debit` を掛けていない。

シールドが強いうちは、船体に届くのはごくわずかで、損傷は緩やかに進む。シールドが弱まると届く割合が急に増え、失われると全部が届く。

v23 までは、シールドのエネルギーが残っている限りビームを全部止めていた。そのかわり、止めた分を全部シールドのエネルギーから差し引いていた。v24 では吸収した分だけを差し引く。そのため同じ火力を受けても、シールドは以前より長くもつ。

## シールドを通らない攻撃

- **航空機**：シールドの内側に入り込んで撃つ。機銃や爆弾は船体に直接当たる。イオン砲も、イオン魚雷と同じく艦そのものに作用する（2026-11-16 のユーザー決定「シールドは艦の周囲に展開される形で、小型機はその中に入り込んで攻撃できる」。それまでは航空機のイオン砲だけシールドで処理していた）。
  - **シールドの殻**：シールドは艦の周囲に、船体より少し大きい楕円体として張られる（各半径 × 1.2 + 20 m、`app.js` の `SHIELD_SHELL`）。試験航行で自機が航空機のときは、目標の殻の内側から撃った弾だけが艦に直接当たり、外から撃った弾はシールドで処理する。艦隊戦・RTS の航空機の攻撃は、殻の内側に入り込んで行うものとして扱う。
  - **表示**（2026-11-16 のユーザー決定「被弾した時にシールド全体を光らせる必要はなく、シールドの位置でターボレーザー、イオンが炸裂するだけでいい」）：殻そのものは描かない。艦の砲撃がシールドに当たると、弾が殻に入る位置でターボレーザーは橙の閃光、イオンは青白い火花として炸裂する（`spaceShieldBurst`、`ellipsoidEntry`）。シールドを抜けるミサイル、殻の内側から撃った航空機の弾は、従来どおり船体で炸裂する。殻で止めるのは、その弾の線が船体に当たるものだけ（当たり判定の大きさは船体のまま、艦隊戦の命中計算と同じ）。損傷は、その線が船体に入る点に記録する。
- **ミサイル・魚雷・爆弾**：シールドを抜けて、全部が船体に直接当たる（以前は半分）。
- **イオン魚雷・イオン爆弾**：実体弾なので、シールドを介さずに艦そのものに作用する（艦の過負荷・熱）。
- **イオン砲**：今までどおり。

航空機とミサイルは艦船より弱いシールドしか持たず、接近するまでに点防御で数を減らされる。点防御による迎撃は今までどおりである。

## 適用範囲

- 艦隊戦（`combatResolve` と `shieldReceive`）
- 試験航行の戦闘（`app.js` の `spaceDamage`）。自機が航空機のときは、機銃の命中が船体に直接当たる。
- 簡易の模擬戦の計算（`simulate`）。ミサイルと航空機の攻撃を船体に直接当てる。

艦の諸元（シールドの容量、回復量など）は変わらないので、作例の設計ファイルや戦闘ファイルは書き換わらない。`js/core.js` が変わるため、`manifest.json` と `data/fleet.js` の記録だけを更新する。
