## 形状と寸法

角形175TTは70TT×3の軍艦型六角砲塔を基にする。連装と三連装は、外殻・砲基部・駆動部・上部機器を同じモデルに揃え、三連装だけ既存の左右2門の間に中央砲身を1門追加する。全体の砲塔本体と砲身の長さ・太さは維持し、175TTの角形・お椀型砲塔では前部機構だけを幅・高さ・奥行きとも0.8倍にする。

調整後の砲基部外殻幅は連装14.4m、三連装14.4m、四連装27m、可動機構全体の幅はそれぞれ16.416m、16.416m、29.016m。連装・三連装の外側2砲身の軸は元の位置を保ち、間隔7.6mの中央へ追加砲身を置く。本体の最大幅位置はX=6mで、取付中心もこの線の中点に置く。上部機器まで含めた現在の全高は16.425mとなる。 縮小した砲基部の両脇は、本体につながる固定の装甲構造で埋める。外形の斜面・楕円の輪郭に収め、俯仰する砲基部との隙間を残す。追加構造に充電容量は与えない。

175TTイオン連装だけは、指定されたIS重戦車風の潰れたお椀型の本体とする。実際に扁平な楕円体曲面を使い、切断面や装甲の稜線は平面の法線を保持する。通常のターボレーザー連装は角形。イオンの本体は前後に長い楕円で、砲基部は通常連装より1.65m前へ出す。720TT連装は、元の175TT角形砲塔を1.5倍にした独立したモデルを維持する。今回の175TT前部機構の0.8倍調整は適用せず、元の寸法90×24.75×67.5m、砲基部と砲身を保つ。

175TTの砲身長は26.25m。ターボレーザーの主部直径は1.65mで、720TTターボレーザーは同じ断面構成を1.5倍にする。球形4種の砲口最前面は共通とし、砲室内に隠れる根元の位置で調整する。砲口には実際の凹んだ内面がある。イオン砲は太い付け根から細い先端へ絞る。生成モデルでは同口径ターボレーザー基準の根元半径2.2倍・先端主部半径1.25倍（175TTでは直径3.63mから2.0625m）を使い、実際に外へ出る部分でそのテーパーが見えるようにする。旧40TTイオン球・小型イオン砲・艦載機用イオン砲にも同じ太い意匠を適用する。

寸法の根拠は[写真の校正と不確かさ](capital-turret-photo-calibration.md)、独立した画像上の点とSHA-256は[測定記録](../assets/source/capital-turret-photo-measurements.json)を参照。斜視・遠近の読み取りを含む推定で、隠れた機構や砲身根元を実測値とは扱わない。

角形砲塔の正面上部と両側の前寄りの角は、下部の裾を残して屋根側ほど後退する斜面にする。[注記付き側面図](../assets/source/capital-turret-front-bevel-reference.json)を基に、175TTの屋根側の前縁は、保持する下端の前縁に対して約10.125m後退させる。元の砲軸へつなぐ一体支持部には充電容量を与えない。

角形砲塔は閉じた装甲上面を持ち、後部の左右2基のスリット付き円形装置、配管・横梁・中央受筒をその上に載せる。中央の開放ピットは作らない。前部には段付きの揺架と同心円状の駆動部、側面には台形装甲パネルと下段の装甲帯を置く。参考図の展示用円筒は作らない。内部の機構や俯仰のための空間を充電区画へ数えない。通常連装・三連装・イオン連装の可動砲基部は、左右の駆動輪を含めて幅16.416mで、本体最大幅45mの半分、22.5m以下という条件にも収まる。

## 球形砲塔の配置と照準

球形175TTの3種と720TT単装の4種は、砲基部・砲身配置・球体を元のモデルのまま保つ。角形・お椀型175TTへ行う前部機構の縮小は適用しない。4種の球径は36mで統一する。取付面をY=0とした球中心はY=6m、下端はY=−12mで、球の下側約1/3が構造物へ入る。球体と砲身を一緒に回し、ケースだけを固定して内部の砲身を動かす形にしない。

新規配置と選択後の編集で、左右角±180°と上下角±90°を指定できる。既存の40TT×4イオン球と500GT単装球も同じ操作に対応する。上下角は `assetPitch` として保存し、複製、テンプレート、対称配置、Undo/Redo、グループ回転に反映する。上下角の指定で取付面の法線や船内給電装置を回さない。表面砲列の埋込窓はこの自由配置UIの対象外。

描画、砲口、選択判定、射線、艦隊戦の照準は同じ変換を使う。旋回軸は取付面の法線、球体の旋回中心は球中心とする。上下90°を越える照準は、同じ方向へ向けられる反対側の旋回・俯仰の組合せも評価する。

## 共通塗装

既存モデルも含め、すべての通常砲塔を現行40TT×8のISD塗装へ揃える。40TT×8自身のUV・色・形状は変えない。他の参照砲塔と点防御・小型イオン・`cturret` は、同じISDテクスチャの屋根の色を描画時に使う。参照色はRGB(143,150,155)、UVは(0.046142578125,0.153564453125)。イオン砲も同じ色にする。

塗装の統一は描画用コピーで行う。既存40TTイオン球は今回の太い砲身へ変更するが、球体・砲口位置・砲室は保持し、残りの参照アセット79個は変更しない。旧40TTイオン球の現行描画数は2,480三角形。内部の黒い砲門、ミサイル、センサー、構造物などは対象外。固定・可動部分、プレビュー、選択、艦隊戦で同じ描画経路を使う。

## ISDと保存設計

ISD作例の主砲位置8基は移動しない。各舷の艦尾寄り1基を175TT連装イオン、残る3基を175TT連装ターボレーザーにする。艦腹のDBY-827 4基も保持する。イオンの艦尾配置は2枚目・3枚目の写真を合わせた方向の推定である。

`stl`・`ion`・`utl` の保存キーと配置IDを保持し、新しいモデルへ移行する。旧ISD連装スキンだけを取り除く。新しい砲室寸法や主砲威力に古い表面集計・艦隊プロファイルを使い回さないよう、プロファイル版と表面集計キーを更新する。

充電容量は見た目の包絡箱ではなく、モデル内の閉じた砲室領域から算出する。可動機構の空間を除外し、不足する充電装置は取付面の背後へ実配置する。球形4種の外形と総球体容積は共通だが、深く差し込む砲身・受筒などの機構区画を控除した閉じたセルだけを充電設備へ使う。共通の保守的な機構用領域8,060.438m³を予約し、総球体容積24,143.884m³から差し引いた16,083.446m³を利用可能な砲室とする。威力による必要容量は型式ごとに計算する。球体の埋設率と利用可能な砲室の埋設率は別に計算する。

## 再生成と検証

- [角形・お椀型マニフェスト](../assets/source/capital-turret-family-manifest.json)
- [球形マニフェスト](../assets/source/capital-ball-turret-manifest.json)

```sh
python3 scripts/build-capital-turret-family.py --check
python3 scripts/build-capital-ball-turrets.py --check
node --test tests/capital-turret-models.cjs tests/capital-turret-core.cjs \
  tests/ball-turret-placement-ui.cjs tests/capital-turret-trial.cjs \
  tests/turret-shared-paint.cjs
node scripts/update-craft-costs.cjs --check
```

幾何検証は全25砲身の凹んだ砲口、閉じた砲室、175TTの共通外形と前部幅、球形の共通外形、可動部の接続・クリアランス、使用頂点の法線を調べる。ブラウザ検証は実際の描画、配置プレビュー、左右・上下角、保存・再読込、Undo/Redo、ISD作例とポリゴン数を対象にする。

大型作例の追加調査は[Executorの限定的な計測記録](benchmarks/capital-heavy-example-opening.json)に残す。変更前でも構築に約164秒かかり、180秒以内の初回表示完了は確認できていない。この記録から今回の変更による速度差は判断しない。ISDの実画面確認とは別の調査である。
