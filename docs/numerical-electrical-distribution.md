# 距離による給電計算

給電線の形状・経路探索・断面・占有容積・質量・費用・独立した損傷パーツを廃止する。反応炉、パワーセル、接続先の電源点を使い、その間の直線距離を艦内の給電距離 `L` とする。既存の接続先、明示した容量、電力系統の分離、共用区間での容量共有は維持する。

機関・武装・シールド・冷却装置・その他の機器は、共通して次を使う。

```
送電効率 = exp(−1e−5 × L)
受電電力 = 送電電力 × 送電効率
送電による発熱 = 送電電力 − 受電電力
```

電力配分では、受電要求を満たすために必要な送電量を電源の予算から引く。複数の機器が同じ接続を使う場合も、その接続の容量と電源出力を共有する。損失は実際に送電した分だけ発生し、全艦蓄熱に計上する。

3D表示と居住容積から給電線を除去し、系統画面には接続先・容量・距離・効率を表示する。電源や実際の機器の損傷は引き続き給電に影響する。

機関からノズルへの動力伝達路は、直線の実体モデルを使う。断面、占有容積、質量、費用、機器との干渉、損傷の計算は動力伝達路に適用する。

検証には、電源・機器の移動、共用容量、損失を含む電力収支、全艦蓄熱、保存・再読込、武装の給電、ISD-I/IIの7基の直線路を含む。実ブラウザの記録は [ISD-IIの表示・公試](benchmarks/numerical-electrical-distribution-browser.json)。`node scripts/browser-straight-imperial-transmission.cjs --electrical-distance` で再実行できる。作例全艦の更新状況とは独立した検証である。
