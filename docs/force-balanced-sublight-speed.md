# 推力と抵抗が釣り合う最高速度

通常航行の速度は、実推力と抵抗の釣り合いで決める。従来の最高速度で速度ベクトルを切り詰めない。TIE/ln100MGLT、ヴェネター級50MGLTを含む従来の速度は、全出力の基準運転時に釣り合う目安として使う。

既存のゲーム内換算 `1 MGLT = 20 m/s` を維持する。したがってTIE/lnは2,000m/s、ヴェネター級は1,000m/sを抵抗校正の基準にする。この換算はゲーム内の値で、正史でのSI単位の定義とは扱わない。[機関の入力定格はリアクター出力を基準にする方式へ移行する](reactor-powered-propulsion.md)。船体密度、骨組み重量、縦強度・慣性制御・配電・熱・燃料の制約は保持する。

## 校正と運動

設計プロファイルの健全時の制約後加速度を `a_ref`、基準質量kgを `M_ref`、従来の基準速度を `v_ref` とする。

```
c = a_ref / (v_ref × M_ref)
k(M) = c × M
dv/dt = a_actual - k(M) × v
v_equilibrium = a_actual / k(M)
```

`a_actual` はその時点で実際に給電された推力から求め、既存の構造・慣性制限も反映する。基準質量・基準出力では `a_ref / k(M_ref) = v_ref` となる。給電損失、優先配分、過熱、損傷によって実推力が下がると、釣り合い速度も下がる。

同じ校正のもとで実推力が25%へ下がれば、線形抵抗との釣り合い速度も25%になる。最高速度で出力を落とした場合は、現在速度からその低い釣り合い速度へ連続的に減速する。無推力時も現在速度から減速し、瞬間的に停止させない。速度・移動量は共通Coreの解析積分を使う。

抵抗を現在のスロットルから再校正しない。低出力にしたときに抵抗まで弱めて、同じ最高速度を維持させない。基準速度を超える初速度も、その値へ切り捨てず、同じ運動式で変化させる。旧速度はAIの航行目標には利用できるが、速度ベクトルを直接制限する根拠には使わない。

## 質量と参照情報

基準質量と係数は設計プロファイルごとに保持する。同じ校正を使う間は抵抗の係数が現在質量に正比例する。艦載機の搭載物による質量補正も、基準プロファイルを先に校正してから適用する。異なる設計の係数は、その設計の基準推力と基準速度によって異なる。

このため、以前の「全艦共通の係数で1億tなら60秒で速度半減」という規則は置き換わる。小型機も、公表速度で推力と抵抗を釣り合わせるために必要な抵抗を持つ。全艦共通の係数、任意の公表速度との一致、小型機の無抵抗航行を同時に成立させたと主張しない。

既存のプロファイルは、保持している有限の機関定格・制約後加速度・質量・基準速度から軽量に校正する。現在出力やダミーの推力を基準にしない。機関や質量の根拠がない情報から推力を生成しない。既存の保存・艦隊・艦載機プロファイルの正規化経路を使い、図面を一斉に再設計しない。

## 出力指令と実出力

構造上限に対して機関が過大な場合、指令25%でも100%でも同じ許容推進入力へ制限されることがある。その場合は実推力が同じなので、釣り合い速度も同じになる。既存の縦強度・推進入力制限を無効にして、表示上の出力段階へ速度を強制的に合わせない。

基準運転時の最高速度と、その時点の実給電・実推力で到達できる速度は区別する。噴射と出力計は引き続き実出力を表す。

## 検証

TIE/ln・ヴェネター級の基準値、同じ校正での質量変化、部分出力、給電不足、構造上限、無出力、基準超過速度、既存プロファイルの校正保持、艦載機の荷重補正を確認する。公試は実際の入力・配電・熱・移動処理を通して、全出力の釣り合い速度から低出力へ下げた際の減速を検証する。

最終のコマンド、結果、ソースハッシュ、実ブラウザ確認と未検証環境はPRの検証記録に記載する。

統合後の結果は[リアクター基準の推進の検証](reactor-powered-propulsion.md#検証)を参照。TIE/ln100MGLT・ヴェネター50MGLTの基準、実ヴェネターの新規生成、実ブラウザでの出力低下後の減速を確認している。
